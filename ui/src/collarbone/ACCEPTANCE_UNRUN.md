- Actual-source editor with exact full-frame source proof, image natural-size check, view/session/owner/draft callback fences. Every point is an explicit click. Add, move by selected point, delete, clear one/all sides, zoom and pan are available; no JSON text field, templates, auto-fill or second-side synthesis.

Half-width is explicitly selected as 4..256 original-source pixels and serialized divided by original-source short side. No clamp or silent simplification.
