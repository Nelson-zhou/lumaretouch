## Authored behavior

- Independent `lnx.collarbone.v1` scalar `/amount`, internal finite 0..1, display 0..100; actual RetouchPanel route, distinct readiness, provenance and canonical people command ownership.
- Actual-source editor with exact full-frame source proof, image natural-size check, view/session/owner/draft callback fences. Every point is an explicit click. Add, move by selected point, delete, clear one/all sides, zoom and pan are available; no JSON text field, templates, auto-fill or second-side synthesis.
- Exactly 1..2 image-left/image-right polylines, each 3..8 explicit strictly interior source pixel-edge normalized points. Half-width is explicitly selected as 4..256 original-source pixels and serialized divided by original-source short side. No clamp or silent simplification. A smaller actual render grid may still refuse its own pixel-space minimums; that refusal is not silently bypassed.
- Strict metadata validator rejects malformed identity/category/confirmations, repeated points, adjacent segments shorter than 2 source pixels, total length shorter than twice half-width, turns of 90 degrees or more, folded/backtracking traces, self-intersection and cross-side intersections.
- Explicit category choices `female` / `elder_female`, labels 女 / 长辈女, plus eligibility and source-visible-anatomy attestations. No default demographic choice. Existing explicit 男 or 儿童 labels block positive review/edit without silently changing labels; neutral recovery remains available.
- Existing body ownership brush remains separately required. Review is tagged only for collarbone and carries source-owned BodyRef, own-face association and manual `review.clavicle`; other body families reject the extra metadata.
- Explicit positive amount creates a private candidate. Before, after and cyan body-skin admission mask must really load and be separately accepted before atomic confirmation. The body-mask overlay is explicitly not presented as a clavicle field or light/shadow sample visualization.
- Owner/source/body/analysis/parameters/geometry/category/confirmations changes invalidate candidate authority. Unknown outcomes use original-request query, not resend. Neutral reset is an exact operation override, not inherited reset or broad cleanup; detach requires authoritative neutral.
- Presets/people transfer copy only strength. Exact target coverage discloses each target's own review hash, category and visible image sides, with strict neutral null/empty metadata. Source masks, traces and applicability confirmations are never transferred.
- Transfer metadata review is not a newly generated per-target batch visual before/after workflow; that remains a disclosed gap.

## Target image review extension (source-authored, UNRUN)

The explicit/confirmed people-transfer route now requires compact frozen target
image-pair metadata, lazy read-only retrieval of each real before/after PNG,
byte SHA-256 and IHDR/display-size checks, a canonical target coverage digest,
and a separate checkbox for every eligible target. This applies to zero strength
as well as nonzero values. Mixed selected people parameters are visible in the
same full-chain candidate, not an isolated collarbone simulation.

Each display uses the full-render output reduced only to longest edge 1024,
with an optional native-display-size scroll view. It is not a full-resolution
quality check. Paged retrieval does not enlarge the existing native mailbox cap.
Token, request, document revision, side, image digest and coverage identity must
match; stale asynchronous responses cannot authorize a newer review. Unknown
mutation outcomes remain tied to the original request and cannot be dismissed
as if no write occurred.

Persistent association now has a source-authored whole-cohort visual route:
the source member appears first, followed by every target, each with actual
frozen before/after image retrieval, its own coverage and an independent
checkbox. A collarbone selection, retained intent (including zero/unlink) or
active member before/candidate state requires this cohort review even when the
new module selection does not include collarbone. Complete ordered image and
coverage acknowledgment remains bound to the single atomic transaction; a
target-only acknowledgment cannot authorize the source member. Higher-priority
explicit face parameters can keep a member unchanged without bypassing review.
Saved recipes are not reinterpreted. If stale active prior support prevents the
actual before-render, the cohort cannot claim successful visual review or use
an invented neutral before-image; explicit recovery/refusal remains necessary.
Generic single-photo preset review remains a separate existing route and is not
claimed to have these batch guarantees. Official AI 3D detection and automatic
category/anatomy inference remain absent.

New model, workflow and paged-transport fixtures are declarations only. No test,
build, typecheck, app interaction, numerical or photographic acceptance ran.
