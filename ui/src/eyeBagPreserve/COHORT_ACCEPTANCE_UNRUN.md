# Persistent eye-bag v2 cohort candidate: AUTHORED / UNRUN

This source addition is not a test pass, build pass, runtime demonstration,
algorithm benchmark, photo-quality acceptance or complete product delivery.
No tests, typecheck, build, product imports, inference or image acceptance were
run in this task. Existing capsule version 1 and scalar intent are unchanged.

## Authored route

- A distinct persistent-association policy explicitly includes the actual source
  member first and all targets in request order. Every member chooses whether
  active v2 may replace its own legacy effect; no default or donor support.
- The selector supports create, patch and full unlink. Known selected v2 keys,
  capsule v2 intent or active source effects require the route. It also exposes
  an explicit opt-in on unrelated generic operations because target-local active
  effects are not fully visible in inventory. Backend rejection is authoritative.
- Every member has independent before AND after ridge coverage bound to its own
  FaceRef and effective source. Active retained effects cannot borrow support,
  use only candidate coverage, or bypass review via a generic non-eye selection.
- Complete mixed render pairs are identical across independently mandatory eye,
  collarbone and portrait families. Each family retains its own proof and ACK.
- Each member must fetch bounded PNG pages, verify bytes/digest/dimensions, display
  both images successfully, then explicitly check its approval. Metadata alone
  cannot activate a checkbox. Source is a real reviewed member, not a donor-only
  thumbnail. Raw full-resolution photographic acceptance is still required.
- The exact source-first ACK, full selected module scope (including empty unlink)
  and immutable token are sent. No support, analysis, recovery or capsule mutation
  data is sent by the image/commit routes. Identical-intent no-op remains a refusal,
  not a fabricated successful cohort or undo record.
- Unknown commits, undo and redo retain original request identities and are
  query-only across hiding and context changes. Reopened cohort ledger markers
  protect new workflow controllers; malformed markers can only tighten the fence.
- Ordinary explicit-face-map neutral-zero reset remains its own non-cohort route.
  It cannot be used to bypass retained active persistent-cohort effects. Shared
  group/alias eye-bag admission is not expanded by this addition.
