## 数值路径和真实限制

`core/hair_colour/lib.rs` 是无外部 crate 的 Rust 数值核心，完整源帧求解一次，
输出 encoded working-sRGB float32 加性差分，而不是替换原图。
除自然黑的单调压暗外，调色在 linear RGB 中保留原有亮度，收缩色度至色域，
软蒙版在线性空间混合；不模糊 RGB，不生成发丝、纹理、发色层次或光源。
光泽使用当前源图内、头发支持加权的局部/较宽邻域亮度差、相对高亮与裁切门限，
均匀头发不获得全局曝光提升。具体原创公式、阈值和 ABI 见 `core/hair_colour/README.md`。

深黑发不会因“薄藤粉”标签自动变成漂浅色；裁黑与过曝数据不能恢复。
噪声、亮色发丝纹理或误分割可能像高光；不存在物理光源识别或逐根发丝保证。
无可信高光时，正光泽请求明确拒绝整个本次准备，不暗中改成整体提亮。
全部恢复可产生零变化并明确报告 `fully_recovered`，不伪报新效果成功。

## 人物归属不是人脸选择

现有 `semantic_sources.py` 的 hair=1 类是整张照片所有头发的真实类别证据。
其保守 confidence-gated 覆盖来自实际 MediaPipe 推理，但不是人物实例分割。
我们不把选中人脸、最近脸、脸框、只有一个已检人脸或图像上下半区当长发归属。

本版强制在专用、未裁剪且未变形的源图视图绘制范围，生成与真实 hair 覆盖相交的
审核图，用户确认仅包含所选人物后才能保留。可添加、减去、撤回一笔、清空草稿、
关闭而不提交、重做审核。现有 source-normalized brush/radial/prompted 机制被复用；
面板本身提供实际手绘路径，提示选区可由已有生产器的合法绑定传入，未另造假模型。
当前不支持无需人工审核的自动人物实例归属。允许只有一个已检人脸仍不能免审核。
两个已启用人物的审核范围在真实 hair 覆盖中重叠时明确拒绝，不按人物顺序抢占。
源图、分析版本、具体人物或配方改变会使审核 token 失效，不静默继续。

## 人物、恢复、项目与跨图边界

- 原创配方 `{version:1,style,strength,gloss}` 默认 strength=gloss=0。
  标量通过唯一 `lnx.hair_colour.v1` people operation 继承；本模块不创建第二套人物图。
- 人物图的 `local_assets.hair_colour` 只存精确 FaceRef + 内容 hash。
  独立追加式 `hair_colour_assets` 存 source-normalized 审核范围与恢复向量。
  记录绑定原片 SHA、原片尺寸、人物实例 ID、分析版本和实际模型 SHA。
- 恢复仅衰减本项发色/光泽差分，不把整张原片盖回，不擦掉其他功能或其他人物。
  撤销由既有人物图历史恢复引用；不可变旧向量保留，项目重开不能遗漏。
- `prepare_bank` 返回现有 `LocalEffect`，完整源图求解并裁成局部差分。
  `apply_source` 在同一个 people deformation map 之前应用。
  `aligned_fields` 将支持/已有高光/恢复通过同一张 map 对齐，不自行估算形变。
- RGB8/RGB16 原尺寸导出必须用已有 people export 路径重新栅格化向量、重新求解
  原尺寸数值场，再按带 halo 的输出 tile 裁切。禁止放大预览 RGB/差分代替原尺寸求解。
  hair 类本身是低分辨率模型证据的采样，不宣称原尺寸像素级分割。
- 不接受 rendered-canvas AI追色蒙版作为 source-normalized 头发证据。
- 跨图只传标量参数；源拥有的范围/恢复不可搬到另一照片。目标缺少审核范围时拒绝，
  必须在目标照片审核。单纯已确认人物关联也不等于目标照片的头发实例支持。

## 保留语义证据的离线重放

`hair_colour_evidence.py` 对实际已捕获的 hair float32 覆盖做有界、无损
little-endian/zlib 编码，记录原片、模型、shape 与内容 SHA。审核资产另绑定这个
证据 ID；同一原片的已冻结证据不能被后来的推理静默替换。项目保存独立证据库，
重放优先校验并读取已有字段，不因本项效果重放而要求下载、加载或运行 ML 模型。
新分析仍需要真实模型；现有通用人物图中的其他算子有其独立证据要求。
无损单字段原始字节上限 64 MiB，整个编码语义库 128 MiB；超限明确拒绝，
不通过降采样或量化假装保持原审核语义。项目容量上限仍适用。

发色独立重放适配器另检查通用人物图：只有其他面部算子全部中性、没有其他面部资产族的
语义输入依赖，而且原实测 landmarks 和 hair 字段都完整时，才允许绕过新模型
分析。此时复用真实保存的 landmarks，skin/exclusion 保持 None，绝不伪造
“模型已运行”的 precompute。其他非中性效果的缺失证据仍须正常拒绝或恢复。

独立身体库不属于上述面部算子限制，仍由身体消费者验证并组合；晚期参考校正/语义追色
也保持自己的保留证据与渲染阶段。身体编辑、面部恢复预览和人物候选准备统一通过
`people_owned_inputs.preview` 转发已拥有的头发与身体输入，避免可选参数遗漏使已有效果消失。
冻结/停放照片导出和参考捕获使用该照片的原片路径、字段与人物图，渲染前后检查原片变化。
