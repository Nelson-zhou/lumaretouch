# Full-source neck fitting boundary (source only, UNRUN)

The transient resolver owns original producer-grid anatomy, genuine full-resolution
working RGB and the exact ordered repair stack. It is not a display-proxy adapter.
The current rendered RGB is used only by the separate current-stage gain applicator.

## Ports

- `neck_wrinkle_inputs.preview(engine, state, assets)` supplies the transient resolver
  and existing support bank only when an active neck amount exists.
- `freeze(snapshot, source, document_state=..., source_path=...)` records source proof,
  original file stamp, active+redo stack digest and active-only replay digest. It adds
  no raster, fit field, persistent cache, second history owner or model result.
- `neck_wrinkle_source.from_engine(engine, state=..., source=...)` captures existing
  host authority. `from_export(spec, snapshot)` consumes the frozen metadata and
  `_neck_wrinkle_repair_inputs`, not already-resized delivery repair masks. Neutral
  export returns `None` before any new decoding or capability requirement.
- `resolve(resolver, face_ref=..., source=..., analysis=..., byte_budget=...,
  cancelled=...)` returns bytes-backed readonly RGB and canonical measured evidence.

Original decode reuses `portrait_fit_source.capture_original`: actual native source
precision, once-only orientation and established ICC contract, no RGB8 delivery
buffer fitting. Derived decode uses the verified immutable creative asset and its
opaque SDR native bridge. Alpha/HDR remains an explicit refusal, never clipping.

Active repair vectors materialize one operation at a time with the exact shared
`repair_source_materialization` and replay through existing `replay_repair_t`.
Original producer-grid analysis resamples once using `people_snapshot.at_dimensions`;
existing observation metadata remains unchanged and does not claim full-resolution
segmentation. Source and repair proof are common across faces; face evidence is
checked separately. Exact hashes and owner guards run before/after capture.

## Limits and acceptance

The budget reserves 256 bytes per full-source pixel plus 64 MiB for active repair
replay, in addition to the existing decoder admission and canonical analysis costs.
This is conservative planning, not a measured peak guarantee or 24 MP acceptance.
Decode and individual repair solvers are not forcibly interrupted; cancellation is
checked at stage and operation boundaries and prevents successful publication.

All product imports, native compilation, tests, performance and numerical/photo
parity remain UNRUN. The fixture file records structural contracts only; it is not
runtime evidence. Existing decoder, repair algorithms and licensing are unchanged.
