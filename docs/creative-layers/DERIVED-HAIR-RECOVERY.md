## Face-owned operator recovery

Admitted recovery targets are precisely the existing nine face delta stages:
facial_wrinkles, lip_makeup, eye_light, blush_makeup, lipstick, eyeliner, eyelash,
brow_makeup and iris_makeup. Global skin/fabric/background recovery is not admitted.

The existing UI workflow obtains an ungrouped source-input capture with purpose
`local-masks`, presents it, requests a real production before/after review and
commits that presented review ID. Derived admission validates this exact live
capture/review owner, actual pipeline source pixels and selected face/graph/source
context. It does not open generic local masks, repair-input capture, source patch
or clone. Exact terminal receipt replay is allowed without a now-expired capture;
different content cannot reuse the receipt ID.

Mutation uses the effective source binding with actual precompute proof. Candidate
preparation forwards its staged immutable support bank explicitly instead of
reading the live pre-commit bank. Preview/export require the exact enabled face
descriptor set, FaceRef, vector content reference, source-frame raster dimensions
and raster hash. Retained vectors, including disabled descriptors, are resolved
against actual effective source and landmark evidence before preview/export.

The global recovery stage remains empty for these managed face rows. Its physical
original provenance stamp remains checked; the effective composite binding is
added to its stage key rather than spoofing the file hash. Existing full-source
export rerasterizes normalized vectors at output dimensions, and existing snapshot
isolation prevents legacy mirrors from applying a second recovery. The normal
operator contribution is attenuated before the common geometry map; no original
RGB is painted over other edits. The existing review, transaction, rollback,
history and receipt owners remain authoritative.

## Remaining implementation map and explicit blockers

Body remains **not enabled**, not partially accepted. Acquisition still reads
physical-original `_src_rgb`; body export is intentionally dropped/rejected for
creative bases. A coherent port must update actual model pixels, normalized
observation/source proof, preview/common map, capture/export verification and
source-switch history together. Existing body render checks currently depend on
physical path digest/stamp. Arm SAM additionally needs bounded immutable-source
worker transport and a pinned model-only float-to-RGB8 transform, shared by proposal
and export replay; passing unquantized float directly or a false original path
would be incorrect. These actions were not executed or enabled in this slice.

General local masks/grouped grading and prompted masks remain **not enabled**.
Their source binding, preview/export, worker acquisition/cache and model-input
proof require a separate complete immutable-source contract. The local-masks
capture exception above authorizes only face recovery, not those edits.

Shared transfer remains **not enabled**. Next work must validate every applicable
raw inherited operation, require target-owned measured analysis even for neutral
transfers, distinguish retained dormant-original graph slices from genuinely
missing targets, and add explicit identity review between private return-new
document owners. No source face mask/landmarks or private graph may be copied as
target evidence.

Transparent/HDR photo return remains refused without flattening/clipping. Existing
memory, source/proxy/minimum-detail and storage budgets remain unchanged. Local QA
still needs real models/native libraries, multi-face overlap/refusal, recovery
before/after, no-double-application, preview/full export parity, stale/cancel/replay,
undo/redo, save/reopen and recovery/package acceptance. Static AST/hash checks are
not that acceptance, and no unconditional 24 MP claim is made.
