# Required local acceptance (all UNRUN)

No items below are runtime passes. Static AST/JSON parsing proves syntax/structure only. Source does not establish buildability, photographic quality or performance.

1. Build original Rust ABI offline with authored packaging script. Execute Rust unit tests separately; test all six pure chromatic weights, achromatic endpoints/gray, partition across RGB cube, relative-vs-absolute, neutral bit identity including negative zero/HDR, nonfinite rejection without output writes.
2. Run engine/tests/selective_colour_fixtures/test_contract.py. Numeric known vector: encoded [0.8,0.2,0.2], red cyan +20, others zero: relative [0.776,0.2,0.2], absolute [0.68,0.2,0.2], tolerance 2e-6. These are authored analytic expectations, not sampled outputs.
3. Every mapped requirement: select each of nine ranges, adjust each CMYK channel positive/negative separately and combined in both modes. Confirm no selected-tab value bleeding. Cross-range overlap and simultaneous strong sliders must be continuous and deterministic.
4. Gray ramp, saturated patch chart and gradients: neutral identity bitwise, full-black/full-white distinct mask behavior, red/green/blue/cyan/magenta/yellow separation; check boundary transitions and out-of-gamut signed/HDR residual. Compare linear vs encoded invocation under matching transfer, RGB16 path with non-8-bit code values, and no unwanted uint8 quantization. Confirm intentional relative zero-ink limitation is explained.
5. Full preview lifecycle: newer slider input aborts current chunks, only latest preview enables Apply after actual compositor present; fresh reused slot/different seq, different request ID, document switch, history action, alternate tool and engine restart all reject stale Apply. Close/unmount/cancel never persist preview. Cancel frame restores committed effects and is current-document correlated.
6. Exact latest preview Apply adds one history record, duplicate request returns original receipt, no dispatcher duplicate. Undo/redo and grouped other effects preserve complete selective recipe. Simulate frame-render/history failures; rollback restores recipe, ledger and dirty bit; failed rollback locks until actual reload. Timeout/transport uncertainty is query/readback only, never automatic re-commit.
7. Project v18 round trip all nine ranges/mode/history. Legacy v1–v17 omission is neutral; hidden selective field in older schema rejects. Unknown fields, bool scalars, NaN/Inf, null, oversized IPC and corrupt recipes reject before mutation. CUBE assets, grading v17 and tone v16 migration remain intact.
8. Portable preset save/import and batch replacement via existing owners: all-target preflight, no image IDs/paths/pixels, repeated preset does not accumulate, invalid target rollback, independent recipe objects, correct one group history transaction.
9. Export RGB8/RGB16/float at multiple tile sizes and full preview: selective once after grading, before monochrome and terminal quantization, tone two-pass prepass excludes it. Crop/rotation applied once. Cancel export during chunks prevents partial final publication. Real portraits of varied skin tones under mixed lighting, monochrome and HDR inspected at 100%; explicitly record halos/banding/skin hue artifacts.
10. UI keyboard/accessibility, numeric intermediate entry, tab retention, reset current/all, mode toggles, sliders while busy, disabled capability, query/reconcile errors. Test repeated open/close and React cleanup without stale cancellation on a new document. Record CPU bridge timings/memory on representative photos and hardware, without claiming GPU speed.
