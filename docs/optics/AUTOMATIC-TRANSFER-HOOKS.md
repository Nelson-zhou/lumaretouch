# Connected per-target automatic optical transfer

Source wiring complete; **not executed or accepted in this task**. The initial manual-only delivery gap is now implemented, not deleted from scope. Optical quality, package build and actual UI/transaction behavior still require Qoder acceptance.

- `lnx.optics_auto.v1` transfers manual scalar intent plus lens-auto and off/smart/horizontal/vertical requests. Source profile identity, matrices and guides are forbidden. Guided source geometry remains intentionally nonportable. Manual-only and automatic scopes are mutually exclusive.
- Engine `prepare_optics` ports feed preset/batch controllers the target's own complete frozen candidate state, after **all selected upstream scopes** and local-mask replacement are applied. The adapter never swaps that target into the live editor. It admits full-resolution decode before allocation, verifies source-bound upstream masks/assets, then renders actual upstream effects and final manual liquify with optics neutral and final crop/upscale/sharpen disabled.
- Target source pixels, source stamp/SHA, model-derived state, complete candidate SHA, target ID/revision, actual rendered input digest, request, NumPy/OpenCV runtime identity and Lensfun library/database identity bind the private preparation record. Candidate-state identity covers retained dataclasses and actual arrays, not just parameter labels.
- Each target independently rematches real Lensfun and performs real line detection/solver/confidence checks, then renders its composed map before freezing the result. Insufficient evidence is a blocked target, not a guessed transform. Preset review shows before/after; batch shows at most the first two comparisons to respect payload budgets, with independent reports/errors for **every** target.
- Both local-mask and optical reviews are required when selected together. Native Rust validates the optical contract; the UI rejects missing or mismatched selected evidence. The old local-mask proof contract is retained. One-shot review tokens and the existing generation/TTL stores remain authoritative; SHA is integrity binding, not authentication.
- Commit validates the complete candidate and every target's frozen record before writes, including current revision/source/model-derived state and actual DB/library/crop solution. It installs the exact frozen recipe, never re-solves or copies the source result. Existing recheck versus skip-and-report, live-render-before-parked-write and rollback semantics remain.
- Batch undo retains exact old optical state plus result conflict keys and revalidates restored profiles/source. It does not run the source request against the old state. Unreviewed legacy/direct automatic install is rejected.

The analysis input for RGB16 stays RGB16 through upstream rendering, then converts to float. OpenCV's grayscale8 detector is only analysis; it never replaces full16 source/output. Final output replays retained intent through the ordinary float global remap and row-banded export. All source-domain locators remain unchanged. The drawable manual canvas is explicitly pre-optics, and final optics is a separate visible read-only proof.

Connected files: `scope.py`, `batch_preflight.py`, `batch_preflight_controller.py`, `batch_sync.py`, `local_grade_preset_review.py`, `preset_controller.py`, Engine's `prepare_optics` adapter ports, native preset validation, preset workflow/review and batch workflow/review. No new broad transaction framework was introduced.
