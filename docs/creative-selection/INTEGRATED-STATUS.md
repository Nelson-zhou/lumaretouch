## Selection path

App retains the selection owner outside conditional workspace mounting. Explicit
acquisition binds current image leaf, source bytes, full canvas, document revision,
transform, existing mask and owner token. Locked ancestors and groups are refused.
Local vector undo is separate from publication and does not create image history.

The original dependency-free Rust ABI produces float32 full-canvas coverage in
bounded tiles. Geometry uses canvas pixel-edge units, not preview pixels. Source
mask projection uses the existing forward affine and bilinear coverage; the
unchanged compositor still applies masks before transforming image pixels.
Existing masks require explicit replace/union/subtract/intersect choice.

Before/after full-composition and source-mask PNGs are generated by the actual
renderer, byte-hash checked and presented before explicit image acknowledgement.
They are whole-frame display proxies, not native-resolution inspection or proof
of high-bit display precision. Only the immutable full-resolution float mask is
published through CreativeHost.commit_document, one canonical history step.
Original pixels, transforms, masks in old history and underlying files survive.
Existing project/assets/return/export code consumes the resulting real mask.

Native requests retain original IDs and engine epochs. Apply is never canceled
or retried automatically. Read cancellation reaches the stdin reader separately,
including cancellation overtaking queued admission. Late callbacks retain exact
source identity. Unknown apply outcomes fence further edits; an explicit actual
project-open event may retire the old workspace fence but retains UNKNOWN outcome
until the user explicitly dismisses it after checking the reopened project.

The 2 MiB native vector request limit, UI operation/point limits, cumulative native
work budget, full-mask working set and existing compositor resource budgets are
explicit admission limits. They do not establish 24 MP performance or all-resolution
support. No smaller final bitmap is silently substituted. Packaging source now
includes the original core, header, licence and numerical documentation; the build
script was not run and missing ABI capability remains visibly unavailable.

## Material path

The App-lifetime independent catalogue supports local files/folders, categories,
search, ordering, selection, moves, rename and recoverable removal/restore. It
stores original compressed bytes, not thumbnail masters or raw RGBA histories.
Selection passes only library UUID, material UUID, revision and content SHA.
The existing ID transaction resolves the actual immutable file with its PNG16/
TIFF16, ICC and alpha contract, rechecks catalogue and current recipe identity,
packs the existing project-owned asset and uses existing history/preview/export.
Catalogue removal therefore cannot invalidate an already saved project bundle.
Current material eligibility remains the original ID 10 MB and decoder limits.

## Deferred, not deleted

Selection does not yet persist editable vector recipes across app restart, target
groups, select semantic objects, expose native-size canvas inspection, or promise
Gaussian feather/vendor pixel equivalence. Subpixel antialiasing and transformed
source-mask representation limits remain documented in NUMERICS.md.

Material library does not implement sky's separate opaque/64 MiB consumer,
official downloadable stock packs, AI scene generation, automatic resource garbage
collection, external-library migration, or cross-process durable mutation receipts.
Unindexed objects from interrupted imports remain counted against storage.
These partial paths do not close either entire official feature or add algorithm
counts for adapters. Existing photographic/HDR/alpha admission limits are retained.

## Recovery and static audit closure

Catalogue reads and selection reads do not taint project recovery. A known selection
apply advances the recovery revision once; a known no-change does not. Outer
dispatch rejection produces a retained catalogue terminal instead of leaving the
UI waiting forever. Native apply settlement binds the retained reviewed mask ID,
hash and exact revision, not merely a request ID.

Unknown selection outcomes retain their original epoch across engine replacement.
The guarded recovery surface can explicitly start a stopped engine and open a
chosen saved project only after confirmation that unsaved session work is discarded.
Starting alone does not clear the old request; only an actual project-open event
permits retiring its workspace lock, and its historical outcome remains unknown.
These source-reviewed paths remain runtime UNRUN.
