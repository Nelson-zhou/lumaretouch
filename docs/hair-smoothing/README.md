# Visible owned-hair directional smoothing — source-only / UNRUN

**Exact requested control:** `control:PC-32472:8`, `ui/src/spec/refine.json:3298`,
`头发柔顺`. Operation `lnx.hair_smoothing.v1`; recipe `{version:1, amount:0..1}`.
The separately listed `PC-32472:9` / `头发柔顺/发丝调整` remains incomplete: its
label does not establish another independently implemented behavior.

This slice regularizes locally resolved **visible owned hair texture** along a
measured signless source tangent. It applies a bounded scalar luminance gain to
current-stage pixels. It is not skin smoothing, a global-blur rename, hidden-hair
reconstruction, flyaway removal, geometric hair straightening, or a new AI model.

## User route

1. Select an actual analyzed current-photo FaceRef and independently review its
   manual hair ownership using the existing hair support owner.
2. Open `头发柔顺`; load the authentic original source, inspect an actual native
   source crop, and observe the texture scale (1–8 native pixels).
3. Paint separate visible target, admissible context and hard protection. Review
   skin/scalp/ears/accessories/ambiguous contacts/other people explicitly. Empty
   hard paint does not imply an automatic occlusion classification.
4. Request the private **complete mixed candidate**. Inspect before, after and
   support/eligibility views, the actual matching native before/after crop and
   diagnostics. A whole-frame display thumbnail is never sufficient consent.
5. Confirm exactly that candidate and all image hashes through the existing people
   transaction. Closing the panel never loses the original pending request.

A valid directionless or completely gated texture can yield an honest zero
proposal. Supported/context-admitted pixels are not a claim of visible change.
Diagnostics distinguish supported, context-rejected, directional and proposed
nonzero-field counts; final current-pixel changes can differ.

## Deliberate first-slice limits

- Authenticated original RGB8/RGB16/RAW16 working-sRGB float32 sources, up to
  32,000,000 pixels. Derived composites are explicitly refused, never relabelled.
- Existing retained manual ownership only. Prompted ownership whose replay would
  run inference is refused, including competing retained claims. No new model is
  downloaded, installed or inferred by smoothing replay.
- New reviews require a proved identity source/output coordinate mapping. Active
  crop/rotation, flip, face/body/hand/hair geometry, liquify and optics make this
  first review route refuse. Confirmed source-stage fields can subsequently
  participate before the common canonical geometry sampler.
- Nonzero generic patch, preset/cohort/shared-person/alias transfer, donor masks
  and generic facial recovery cannot authorize smoothing. Explicit independent
  zero and detach remain available without native fitting/model availability.
- No claim of photograph quality, performance, build compatibility or runtime
  acceptance is made. Qoder/local testing remains the execution owner.
