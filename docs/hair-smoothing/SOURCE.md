# Source, ownership and review proof — UNRUN

## Existing evidence, not invented semantics

The existing bundled six-class producer's `max(2p-1,0)` hair channel is an editing
weight, not raw probability, matting, a full-resolution re-inference, or a person
census. `hair_colour_analysis`/`hair_colour_evidence` validate actual producer,
model bytes, source binding, dimensions and retained weight content. Smoothing
uses those exact retained observations, not a proxy-derived new classification.

Each smoothing asset lives in `people_support_assets` with the established
`{version, face_ref, source, row}` envelope. `row.target` is the independent
`hair_smoothing_visibility`. It retains the exact hair asset hash, separate
ownership review key, semantic identity, original/repair packet proof, all
retained-source-faces digest and its own target/context/protection/scale consent.
Hair tint/recovery content changes alone do not rebind ownership or silently
revoke the same ownership review key. Historical bytes remain append-only.

All retained source faces enter the ownership digest: enabled, disabled, manually
added and unresolved. Every retained manual hair claim is rasterized for conflict
proof, including disabled claims. Overlap refuses the whole requested effect;
face ordering never allocates disputed hair. Unknown/unclaimed people are not
magically detected: explicit independent hard protection and human review are
still necessary. Prompt-only replay claims are refused rather than inferred.

## Authentic full source

`hair_smoothing_source` is a private-token source adapter following established
source plumbing, not a caller RGB-plus-hash API. It uses `portrait_fit_source`
original decode, its EXIF-once canonical grid, native precision and file hash/stamp
checks. Ordered repair replay uses existing source-capture plumbing, not neck
numerics. Original and repaired source fingerprints must match retained consent.
Original source, analysis and repair allocations are budgeted before measurement;
no thumbnail, cached preview or same-size RGB8 substitute can stand in for genuine
high-bit-depth source pixels. Derived creative source proof is rejected by both
live and frozen export factories.

## Review coordinate proof

The acquisition guard explicitly audits all currently registered face operations
as geometry or nongeometry; unknown additions refuse until classified. Effective
geometry of every enabled source face is considered, not just the selected one.
Body/hand geometry, manual liquify, crop/rotation, final flip and optics have their
own neutral checks. Ignored legacy mirrors are not mistaken for active geometry.
The guard is repeated at capture/revalidation and immediately before publication.

The private reference retains the actual integer source crop rectangle and PNG
hash. Preview requires that rectangle to intersect genuine numerical eligibility.
Full mixed rendering must report canonical source and output dimensions. Before,
after and confirm must name the **same** actual native rectangle. Cropping slices
full native RGB first and never resizes it. Later geometry replay does not pretend
that an old source rectangle is a newly reviewed output rectangle.
