## Numerical and ownership cases

1. Full unit protection and preservation=1 produce exact source bits for this
   operation before geometry, including signed zero; zero delta remains neutral.
2. Preservation=0 exposes only the existing solver correction on reviewed eyes.
   Neither this endpoint nor strength=1 is a complete-removal guarantee.
3. Fractional masks blend proportionally. Entirely feathered/subunit coverage
   cannot be accepted as proof of a completely protected ridge.
4. A left-only review leaves the unreviewed right eye untouched and reports why.
   Hidden, misidentified, foreign-person and stale landmark/source regions refuse.
5. Very small or strongly foreshortened eyes respect the retained solver guards.
   False anatomical certainty is never inferred from zero changed pixels.
6. Red-eye, dark-circle, vein, catchlight and other effects remain independently
   active. Their deltas are not erased by the new protection.
7. New-stage composition uses available RGB headroom, not per-channel clipping.
   Active invalid/HDR inputs refuse; an existing opaque SDR path is not HDR or
   transparency support.
8. Compare actual preview and full-resolution PNG16 export at native pixels,
   including crop/rotation/common face geometry and image boundary cases. There
   must be no tile seam, resized proxy mask, repeated source color conversion or
   original-image analysis substituted for a derived source.

## Photographic limitations requiring real evaluation

Manual markings can be anatomically wrong. Makeup, lashes, glasses, hard light,
deep folds, expression, low resolution and occlusion can make the existing
frequency/crease solver unsuitable. Evaluate skin texture, local color, haloing,
eye contour, identity, paired-eye balance and headroom interactions on diverse
authorized photographs. The source implementation supplies no such evaluation.

Automatic ridge identification, vendor numeric parity, complete removal and
broader automatic AI blemish correction remain outside this bounded path.
