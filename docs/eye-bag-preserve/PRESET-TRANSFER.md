## Scalar-only transfer and local evidence

A portable preset contains only the versioned eye-bag amount and preservation
amount. It never carries painted ridge coverage, recovery vectors, source pixels,
FaceRefs or a reusable approval. The target must already own independently
painted and reviewed per-eye ridge support under its actual source and measured
face evidence. Missing, foreign, modified or stale support refuses active use;
the user must paint/review that target locally first. An unreviewed eye remains
unchanged, not inferred to have no ridge.

The dedicated current-photo route plans all selected supported preset modules,
not merely an eye-bag overlay. It compares actual complete canonical full-source
before/after renders, with bounded RGB8 display pages. Exact owner, source,
repair, graph, support and preset identities bind the image acknowledgment and
subsequent transaction. Supported original and opaque derived sources retain
separate immutable identity and analysis; an original snapshot cannot authorize
an unrelated derived composite.

## Legacy behavior and publication

Replacing existing legacy eye-bag intent requires an explicit target-local
choice. It must not silently clear dark circles or unrelated enhancement leaves,
reinterpret old saved numbers, or discard a separately selected conflicting
legacy effect. Amount-zero reset remains the prior dormant path and must not
clear legacy intent or require active ridge analysis/native processing. Original
and source-bound derived neutral scalar resets retain this separate route.

The existing exact mixed-preset planner supplies the graph used for rendering
and actual replay. Publication and rollback stay under the existing preset
transaction, canonical people owner and ordinary document history. The image
cache and private plan are session evidence, not another asset/history owner.
An uncertain apply remains query-only using its original request, token and
acknowledgment; no automatic resubmission is authorized.
