# Shared-source direct eye-bag editing

Status: source development only. Runtime, rendering, numerical, photographic,
history and project-reopen acceptance remain UNRUN. This workflow adds no new
algorithm. `LNX-REF-PC-32464-C-e5fac5fdcf` remains partial because the lower-lid
ridge is manually reviewed, not automatically segmented.

## One shared source, every affected photograph

The direct active editor distinguishes independent photographs from aliases
that already share one project portrait owner, effective source and FaceRef.
It does not create a new association, clone a graph, or transfer another person's
mask. The shared graph legitimately owns one immutable source-geometric ridge
record. Changing its descriptor changes all documents that resolve that graph
for that source, so reviewing only the current photograph is insufficient.

The versioned alias review enumerates the complete affected live set, current
photograph first, and shows every member's actual full mixed before/after render.
Each member keeps its own complete document recipe, repair stack, crop, output
geometry and source proof. No correction bitmap is copied between members.
The existing eye-bag solver recomputes its delta from each member's actual input.

The native source crops in the painting editor inspect the CURRENT document's
source/committed-repair stage. They are not represented as separate repaired
native inspections of every alias. The shared preservation vector is geometric
support, not a claim that all aliases have unchanged photometry. Each alias's
full mixed images and exact repair/context fingerprint remain independently
bound and must be acknowledged. The authoritative support overlay is separately
loaded and acknowledged; a browser stroke preview is not an authoritative mask.

## Versioned proof, unchanged old behavior

The existing single-document review remains version 1. Alias review version 2
retains the same recipe, source-owned support digest and current visual, and
adds an ordered complete member list. An image request identifies its exact
member; support-overlay retrieval is scoped to the current member. Confirmation
binds every member's revision and image hashes plus the support overlay and
complete review digest. A changed source, repair, graph, asset or affected set
invalidates the review rather than silently recomputing an accepted candidate.

No old eye-bag recipe, scalar association capsule or numeric solver is migrated.
Explicit legacy replacement still clears only old eye-bag strength, and ordinary
neutral reset keeps its separate existing semantics. Unreviewed eyes remain
untreated. Independent preset, ordinary batch and persistent cohort proofs do
not substitute for this direct-editor alias proof.

## Publication and protected history

The existing scoped graph ledger is the only publisher/history owner. The new
alias history marker is deliberately separate from face-style's scalar-only
marker: eye-bag editing also replaces exactly the selected face's immutable
ridge descriptor. It must not authorize arbitrary face analysis, other local
assets, recovery vectors, associations or unrelated parameters.

History binds complete before/after graph state, separately corresponding
before/after support/context evidence, every member's source and nonportrait
recipe, and the exact affected membership. Undo/redo and save/reopen must retain
that closure. A later hidden sibling, unavailable member, changed repair or
support record cannot silently join the old review. Unknown confirmations or
history writes remain query-only, tied to their original receipts; dismissing
the editor is not evidence that a write was canceled.

## Explicit limits

- Two to sixteen fully available affected documents. Unavailable saved aliases,
  ambiguous pending imports and source-switchable dormant affected histories
  remain refused rather than admitted from metadata alone.
- Supported opaque SDR original/derived source only. Existing full-source,
  native-crop and display memory/size limits apply without proxy promotion,
  source quantization, HDR clipping or silent member omission.
- Full mixed review displays remain bounded RGB8 reductions, not native-pixel
  photographic acceptance. Current source crops retain their native spatial
  contract and RGB8 display distinction.
- This slice is direct active editing. Shared-source preset application needs
  its own complete mixed-preset affected-set planner and remains a separate gap.
  Effect-recovery painting is not implicitly admitted by this editor route.
- No new third-party code, model, weight or license is introduced. Existing
  pinned solver and original Rust protection core stay unchanged; see
  `REQUIREMENT-AND-RESEARCH.md` and `NUMERICAL-CONTRACT.md`.
