# ADR-0001 · 代码许可选定与模型分发分层策略

- 状态：**已采纳（2026-10-18）**
- 决策人：本代理（用户授权"由你补齐 LICENSE 声明与模型许可台账"）
- 相关：`LICENSE`、`NOTICE`、`docs/model-licenses/`

## 背景

项目定位由用户明确为**纯开源、非商业自由软件**，无商业变现与闭源销售计划。
此前所有许可判断的坐标系是"可商用影楼发行"，因此把 InsightFace / MediaPipe /
GFPGAN / CodeFormer / face-parsing 一律列为门禁阻断。定位改变后需要重判。

同时存在一处**已经错了的事实**：`engine/pyproject.toml` 此前声明
`license = { text = "Apache-2.0" }`。Apache-2.0 单方面授予任何人**商用**权利，
而发行包准备内置仅授予非商业使用权的第三方权重 —— 元数据与实际权利不符。

## 决定

### 1. 代码许可：GPL-3.0-or-later

全文置于 `LICENSE`（取自 `/usr/share/common-licenses/GPL-3`，标准文本未改动）。

选它的理由（按权重排）：
- **copyleft 让声明链条不断**：下游分发者必须同时带上源码、`LICENSE` 与 `NOTICE`，
  而"本发行物含非商业权重"这条告知正是写在 `NOTICE` 里的。宽松许可（MIT/Apache）
  允许下游把声明文件整段丢掉。
- 与我们的依赖矩阵兼容：GTK/WebKitGTK/LibRaw 是 LGPL 系，PyTorch BSD-3，
  Tauri MIT/Apache 双许可，均可与 GPL-3 组合作品。
- 不选 AGPL-3.0：本项目是本地软件、无服务端，AGPL 的网络条款用不上，却会把
  合规负担转给所有下游。

**必须如实记录的一处矛盾**（不做掩盖）：FSF/OSI 对"自由软件"的定义**明确不允许
非商业限制**。所以"自由软件 + 非商业"在术语上是冲突的，实际含义是：

> 代码本身是自由软件（任何人可行使四项自由，含商用代码的自由）；
> 但**本发行物**因含仅非商业授权的模型权重，整体不得商用。

要法律上真正阻断商用，只有两条路：把代码也改成 NC 类许可（那它就不再是自由
软件），或者不内置任何 NC 权重（那"开箱即用"就没了）。当前选择是两者折中，
靠"上游权重许可天然阻断 + 明确告知"实现意图。这一点必须让任何后续贡献者知道。

### 2. 模型分发：三档分层

| 档 | 内容 | 载体 |
|---|---|---|
| `bundled` | 核心精修全流程所需：0 权重的磨皮/调色管线 + MediaPipe 478 点模型束 | 进 deb，装机零操作 |
| `fetched` | 重型生成模型（LaMa、CodeFormer 等，数百 MB） | 首次点击该能力时一次性清单确认 → 自动拉取 → 之后静默更新（哈希校验） |
| `blocked` | 许可核不清且无法用上面两档承载 | 功能显式禁用 + 说明缺什么 |

主包体积上限作为设计约束：**不因模型胀破 1 GB**。

### 3. 拒绝一项授权范围内的做法：纯静默拉取

用户方案里"首次启动静默拉取"这一半未采纳，改为一次性清单确认（仍是一次点击，
用户不需要手动挂载任何东西）。理由与商业侵权无关：

1. 我们对外承诺不外传照片/特征/EXIF，则**入站**网络动作须同等透明；
2. Apache-2.0 与 CC-BY 类许可要求**许可文本与署名随副本分发**。静默下载会让用户
   机器上出现他从未见过的许可文本，署名义务直接落空。

### 4. 非商业定位下重判放行

InsightFace（仅非商业研究）、face-parsing（CelebAMask-HQ 协议）、CodeFormer
（S-Lab License 1.0）、GFPGAN（NVIDIA StyleGAN2 权重 + FFHQ BY-NC-SA）——
这些限制的适用条件都是"非商业"，本项目符合，故**允许实现与个人使用**。

但三处许可性质必须纠正（它们不是用户方案里说的"CC BY-NC 4.0 或 MIT/Apache"）：

| 资产 | 真实许可 |
|---|---|
| InsightFace 预训练包 | 作者自述"仅非商业研究"，非标准许可文本 |
| CodeFormer | **S-Lab License 1.0**（自定义非商业许可） |
| face-parsing 权重 | 代码 MIT，权重受 CelebAMask-HQ 数据协议约束 |
| GFPGAN | 代码 Apache-2.0，依赖 NVIDIA StyleGAN2 权重许可 + FFHQ **BY-NC-SA** |

"非商业"免除的是**取得商用授权**的义务，**不免除**署名、许可文本传递、SA 传染
与肖像权。这几项照做，写进 `NOTICE` 与台账。

### 5. 评测靶改用公认学术集

采纳：FFHQ / CelebA-HQ / CelebAMask-HQ 作本地评测靶，取消"商业采购授权"约束。
附三条硬规则（见 `docs/model-licenses/README.md`）：靶集不进仓库/包/不外发图像；
FFHQ 的 SA 传染性；官方禁止身份识别用途 → 本项目不得实现跨照片认人。

## 后果

**变好的**
- 面部重塑 / 智能消除 / 换底三个 AI 族解除阻断，可以按纵向切片推进。
- 许可判断有了单一事实来源（`models.json`），不再靠聊天记录和记忆。
- 定位落到文件里，贡献者不会再误以为可商用。

**变差的 / 待办**
- GPL-3 要求随二进制提供源码或书面要约：deb 安装时必须能指向源码获取途径（待补
  进 `debian/copyright` 与包内说明）。
- 台账里所有 `sha256` / `size_bytes` 目前是 `null` —— 这些数只能来自真实下载实测。
  **在填上之前，`bundled` 档其实还没真正成立。**
- MediaPipe 模型卡一手复核未做（本环境访问 HuggingFace 返回 401），结论目前是
  二手证据；LaMa 的 Places2 条款待复核。
- `NOTICE` 与 `docs/model-licenses/` 需要真的装进 deb 的 `/usr/share/doc/`，
  否则"许可文本随副本分发"仍是纸面义务。

## 备选方案（都考虑过，未采纳）

| 方案 | 未采纳原因 |
|---|---|
| 代码保持 Apache-2.0，代码与模型包拆成两个产物 | 干净，但要求发行流程真的拆开发布物；当前 deb 是单产物，且与"开箱即用"冲突 |
| 代码用 CC BY-NC 4.0 | 能真正阻断商用，但它**不是自由软件许可**，与用户"自由软件"的表述直接冲突；且 CC 系许可与 GPL 不兼容 |
| 全部权重都内置（不做 fetched） | 主包胀到 1 GB 级，且把 Places2/S-Lab 这类未复核条目一并背进发行物 |
| 全部权重改为用户手动挂载 | 与 C 端极简定位冲突，用户已明确否决 |
