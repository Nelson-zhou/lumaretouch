# Reviewed upper-body-length scalar transfer

Source-only continuation of `LNX-REF-PC-32473-C-f1662d2dec`, not a new handbook count. The original numerical method, native ABI, source-space support, common sampler and manual-assisted upright applicability remain unchanged. All runtime, compilation, numerical, UI and photographic acceptance is **UNRUN**.

## Bounded product route

The existing preset library and frozen batch controller carry only `{version: 1, amount: [-1,1]}` for `lnx.torso_length.v1`. Torso must be the only selected module. No complete body bank, BodyRef, face identity, person association, pose landmarks, review, support boundaries or masks are portable preset data.

This first route admits exactly one enabled body in a target's retained source-owned bank. That body must already have its own enabled torso operation, independent support review and current explicitly confirmed association to its own observed face. Multiple enabled bodies refuse, even if only one appears suitable. Disabled or unresolved retained anatomy remains relevant to the existing geometry exclusion checks. This is a disclosed restricted selection policy, not automatic cross-image person recognition. A preset amount may be applied to different people only after their own independent ownership and visual review; the source person's identity is never inherited.

Before publication, each target is rendered twice through the actual full-source canonical exporter, with its own original or immutable derived pixels, current body bank and portrait context. The bounded PNGs are reductions of those completed renders, not proxy-coordinate deformation inputs or photographic acceptance. The display transport retains the existing eight-target and 256-pixel-edge review bounds. Failed source, support, geometry, memory or native-kernel admission refuses the target rather than silently reducing strength, choosing another person or omitting existing edits.

The compact proof binds document/revision, immutable effective source and original provenance, complete before/candidate state identities, target people-context identity, BodyRef, associated face evidence, support/ownership evidence and exact image hashes. Every eligible target's two decoded images must be reviewed and acknowledged in the frozen order. Changing the source after scalar capture does not change that frozen amount; changing the target invalidates its review. No source masks or inferred association are installed.

## One publication and history owner

The general frozen preflight store, preset receipt owner and batch ledger remain authoritative. No direct torso-host edit is repeated for each target, and no second transaction or undo stack is introduced. Tokens are claimed before mutation; uncertain outcomes retain exact acknowledgment and remain query-only. An unchanged recipe is not permission to skip source/ownership review.

Scoped restoration modifies only the selected torso recipe in the target bank. Dependency checks retain exact target anatomy, support, association, other operations and source identity. Monotonic bank revision is not mistaken for changed visual intent, but the reviewed candidate proof still binds its exact bank version. Actual current face/support consent must remain valid on group undo/redo; changed ownership refuses rather than rebinding stale consent. Existing per-document history remains distinct from the session-only batch group ledger. Cross-restart group undo is not claimed.

## Limitations

- Multi-body target selection is not implemented by this bounded transfer route; use the existing direct per-body editor instead.
- Target analysis and support authoring must be completed beforehand. Transfer does not run pose acquisition or invent missing anatomy.
- Other private-helper-only body families remain unconnected to this route.
- Existing original/derived source restrictions, alpha/HDR refusal and whole-image geometry checks are preserved. No silent clipping, source-mask copying or fallback filter is added.
- Waist length remains a distinct unfinished requirement. The torso requirement remains partial pending actual runtime/numerical/photographic and broader applicability acceptance.

The foundation's official guide and primary-method references remain in `IMPLEMENTATION.md` and `NUMERICAL-CONTRACT.md`; no new numerical algorithm, model, weights or third-party code is introduced here. The implementation is original project GPL-3.0-or-later source.
