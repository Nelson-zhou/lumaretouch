# Lens host acceptance matrix: NOT RUN

This is a future authorization-dependent verification plan, not executed tests,
performance evidence or an acceptance claim. Use real photographs and real
packaged Rust libraries; never fabricated image/native success fixtures for
product acceptance.

1. Exercise complete source acquisition on ordinary, high-bit, RAW and derived
   photos with real edits/crop/rotation/layers/repairs. Verify captured canonical
   identity and actual dimensions, not original-file or display-image hashes.
   Confirm capture intermediates stay in a job-local store and nothing reaches
   source rows, project assets or undo before explicit save-copy.
2. Refuse actual alpha/signed/HDR captures and unsupported active edits without
   flattening, clipping, deleting the original or silently skipping an effect.
   Test unavailable/disabled/incompatible lens and creative native libraries.
3. Begin with no depth. Verify only an explicit manual acknowledgement creates
   the constant plane, exact 0.5 quantization, original acknowledgement ID and
   session ownership. Verify the original source PNG stays the same. Model and
   subject mode must remain unavailable; no inference or download may occur.
4. Compare exact protocol-2 commands/reviews/receipts with UI validators. Refuse
   version-1 wire envelopes, extra fields, missing return mode, falsified result
   hash, source/hash/dimensions/orientation mismatch and oversized requests.
   Keep numeric recipes and depth assets version1, with no saved-intent reset.
5. Render every real native aperture with full-source depth/brush controls.
   Compare actual canonical output and full-frame PNG samples. Verify display
   pixels never become returned pixels. Inspect complete before/after images,
   decoded natural dimensions and re-presentation after panel remount.
   Verify point-focus sample/interval validation at raster/source borders,
   bilinear interiors, clipped near/far ends, zero-width intervals and manual
   plane quantization; unrelated point labels must reject. Sliders use interval
   mode. The binary64 tolerance must not modify accepted numeric controls.
6. Change row/index, version owner, workspace epoch, revision, creative nonce,
   load ID, file stamp/content and people graph at every operation boundary.
   Confirm hot polls avoid full hashes and cold boundaries detect byte changes.
   No stale candidate may cross the final precommit source fence.
7. Exhaust source, combined leases, native taps, refinement work, PNG payload,
   outer/inner request, graph/document count, sessions, reads, writes and receipt
   bytes separately. Observe refusal before new uncontrolled retention. Verify
   no proxy, radius reduction, stroke thinning or old write-receipt eviction.
8. Expire source/candidate leases and replace manual planes/previews repeatedly.
   Reclaim bytes while preserving exact unknown write proof and terminal
   receipts. Test phase-specific failure cleanup and later explicit recapture.
9. Send cancellation before admission, during capture/hash, depth preparation,
   native tiles and PNG conversion. Observe the original job actually unwind
   before cancellation success. Test mismatched read hash/session owner/token,
   queued cancel then apply, and late native completion after cancellation.
   Measure actual cancellation latency through existing unpolled bulk fill,
   serialization and asset-validation/hash regions. Cooperative deadline polls
   are not a hard 120-second cancellation or process-kill guarantee.
10. Apply once after exact full-image acknowledgement. Verify distinct new row,
    canonical result hash, actual runtime result revision, original row and
    original history preserved. Repeat with neutral output: still a distinct
    image, `no_change:true`, same canonical hash, no invented source history.
11. Duplicate the exact write and query it under a fresh outer mailbox ID.
    Neither may run the transaction again. Alter each field under the same
    request ID and ensure rejection without replacing the original receipt.
    Remount/unmount and switch documents without replacing the receipt owner.
12. Drop the response before/after commit, fail emission, fail cleanup and inject
    a common transaction/readback error. Confirm pending/unknown fences and
    positive exact-row reconciliation only. An absent/ambiguous copy is unknown,
    not rejected/cancelled/safe-to-retry. Generic dispatcher errors must not
    override a known stored receipt.
13. Cancel after apply has begun and after applied readback. The reader must not
    interrupt the commit. A later cancel cannot roll back or claim the copy did
    not occur. Unknown writes allow only original-query or safe shutdown paths.
14. Save/reopen the actual new canonical image using common project storage;
    inspect full-resolution export and later ordinary editing. Verify original
    photo/history remains intact. Do not claim a persistent adjustable lens
    recipe layer or crash-durable lens receipt unless separately implemented.
15. Run final authorized lint, tests, typechecks and builds for all shared
    registrations. Complete real desktop/UI/visual acceptance separately from
    static AST/hash checks. None of those execution stages ran in this lane.
