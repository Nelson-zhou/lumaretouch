## 本轮新增那一臂在看什么（LNX-PORTRAIT-003 分人编辑）

`LRT_LOAD_IMAGE=engine/tests/fixtures/portrait-dual-1570x950.jpg` + `LRT_PRECOMPUTE=mediapipe` +
`LRT_AUTO_FACE=1`：一张两个真人的图，让引擎自己报有几张脸，然后**点选 1 号**（不选 0 号——选 0 验不出
"认的是那一张"还是"谁都是第一张"），再推同样的三个滑块。四句话缺一不可：

1. 未选定就推形变 → 引擎**整条拒**（SCOPE-001）且画面 0 字节变化：拒绝不许留半截状态；
2. `runFace → Rust face → face_selected → status.face` 这四层签名对得上（`pickSource=face_selected`）。
   裸引擎那九段判据全绿也覆盖不到宿主这一侧——本轮第一轮就是它抓住了"事件把状态平铺 splat、而宿主读
   的是嵌套对象"这个形状错（详见 ADR-0011 §3.3）；
3. 点选本身不改画面（`changedBySelect=0`）：选人是换个服务对象，不是调了一次图；
4. 选定后推形变，**没被选中的那一圈逐字节不动**：`insideChanged=55018` 而 `outsideChanged=0`（以选定
   那张脸的脸心为心、1.6× 脸半对角之外必须一格不动；半径来自 ADR-0009 §2 的实测支撑窗，实测最远变化
   1.58R），`support_share=0.3316` 顺带说明作用面不是整幅。

其余各臂（拖拽/导入/缩略图/形变/局部调色/换底/导出/历史/DNG 直通）与上一轮同一批判据，一并列在下面。
