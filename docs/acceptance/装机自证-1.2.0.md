## 这一轮新补的两臂（此前装机校验里根本没有）

| 主张 | 旧校验验了什么 | 本轮验的判据 |
|---|---|---|
| 内嵌 FaceMesh + GPU 毫秒级面部重塑 | `LRT_PRECOMPUTE=template`（网格占位几何，引擎自己拒它做形变）——等于没验 | landmark_backend 必须 `mediapipe`、built/lit 为真、deform_ms < 60、peak_px > 0 |
| 拖入 DNG 即刻精修与高质量导出 | 只有 jpg 臂；对 RAW 通路没有推论力 | 生成器/引擎/磁盘 IHDR 三处尺寸对账 + 导出后原片 sha256 逐字符比 |

## 仍未闭合（写在这里而不是省略）

- **真人照片输入未验**：本机没有可授权的真人素材；现有证据来自本仓程序化夹具。所以"任意拖入真机人像"只对**通路**成立，不对**观感**成立（同 PORTRAIT-002 盲评规程"待补：真实人像"）。
- 人工签字仍缺：PORTRAIT-002（自然度）与 PORTRAIT-007（背景异常）状态是 `manual_pending`，不算通过。
- 形变在紧支撑圆**内**会带动背景（实测随形变量线性增长），判据建在"圆外逐字节为 0"这条引擎自报不变量上；见 ADR-0009。
