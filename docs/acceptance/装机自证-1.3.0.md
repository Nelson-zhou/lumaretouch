## 本轮新增那一臂在看什么（COLOR-004 局部调色）

`LRT_AUTO_LOCAL_COLOR=0.5:0.42:36:0.006:-0.14:0.05`：在代理帧归一化 (0.5, 0.42) 处落一笔半径 36 px 的区域，
再给肤色定向层递一份增量（dh=+0.006 / ds=−0.14 / dv=+0.05）。真窗口这一臂要同时证三件事，缺一件都不算接通：

1. `runGrade("mask"/"set")` 这两个新 action 在 **Tauri 命令签名**上递得到——签名写错时画面不动而一个错也不报；
2. 落笔后作用域是**引擎自己**切成 `brush` 并随 `grade_done` 报回来的（`scope='brush'`、
   `scopes=['all','skin','brush']`、`mask_px=4654`、`bytes_grade=806400`＝代理帧 400×504×4 的权重层，
   `grade_ms=4.34` 说明定向内核真跑了那一帧）；
3. **区域外逐字节不动**：拿用户看见的那一帧逐格比 before/after，`insideChanged=4396` 而 `outsideChanged=0`。
   最后一条只有一份证据——屏上没有第二块画布可比，而"局部调色静默变成全图调色"恰恰是画面在变、
   人分不出来的那种错（库层用例连的是裸引擎，中间隔着 Rust 那一层）。
