# LumaRetouch 1.12.1 · 去工程化视觉整改与真窗口自证

> 目标：把 1.12.0 的「规格工作台」从研发看板改成商业修图软件的操作界面，同时
> 不删除任何规格数据、不缩减已接通能力。

## 1. 整改内容

| 用户指出的问题 | 1.12.1 的处理 |
|---|---|
| 标题、搜索框、Tooltip 里的 `PC-xxxxx` | 全部从可见界面移除；搜索框改为「搜索功能，如 磨皮、瘦脸」，只匹配中文功能名与规格 path |
| `39 族 · 805 项`、`45 项`、`已接通 4`、`中性灰立体 3` | 可见计数徽章全部删除；`data-spec-total` / `data-spec-controls` 仍留在 DOM 供发布门禁对账 |
| 黄色 `P1 规划中` 胶囊 | 全部删除；未开放项走 `DisabledRow`，文字淡灰，原生 Tooltip 只说「该功能将在后续版本提供」 |
| 顶栏 `0%` | 无图时整个缩放条不渲染；有图但 `fitScale` 未就绪时用 `100%` 占位；100% 档位仍随窗口重算 |
| 视口工具条太像调试条 | 「单视图 / 并排对比 / 卷帘分屏 / 按住看原图 / 裁剪」收进顶部悬浮胶囊；「适合 / 100%」收进右下角悬浮胶囊 |
| 折叠栏像 JIRA 卡片 | 去掉每族的边框、底色、计数与规格 ID，只留中文标题 + 细分隔线；概述/常见问答不再占版面 |
| 滑块只有裸数字 | 每个滑杆右侧加数值输入框；EV / K / % 单位独立排版；滑块轨道按中点/左端起填 |
| 空状态与各处开发话术 | 空状态改为单线卡片 + 加号入口；创意与导出工作区同步清掉 P1、工具/分类计数、`工作流 32483` 与 `AdobeRGB · P1` 等字样 |

规格 JSON 未改：`ui/src/spec/*.json` 仍与资料包逐字节一致；`buildTree` / `SpecNodes`
仍是功能清单的唯一出处。概述与常见问答保留隐藏节点，39 族的数据契约没有丢。
引擎与算法没有改动，1.12.0 的引擎级验收与性能分位数仍适用；1.12.1 只改 UI 与版本号。

读法：

- `bads=[]`：自动臂内的参数/画面/裁剪/100% 判据零红项。
- `families=39`：隐藏的概述/问答节点仍计入 DOM 数据契约；可见折叠栏是 28 个
  产品功能分组。
- `specControls=805`、`hslChips=9`、`sliders=27`：子控件、八色 chips 与真滑块
  一个没少。
- `zoom=100%`：隐藏的 `.zoomRead` 仍供探针读取；界面在 100% 档位不重复显示
  一个“100%”读数。
- `pixelated=0`：所有 canvas/img 的计算样式都没有像素化重采样。
- **版本串与脱敏**：本日志捕获自「UI 已按 §1 清洗、但 `release-version.py sync 1.12.1`
  尚未跑」的中间构建，`M0_ENGINE.version` 因此记为 `1.12.0`；界面读数（`groups=28`、
  `sliders=27`、`families=39`、`specControls=805`）对应的就是本次交付的 1.12.1 UI 代码。
  1.12.1 端到端由 §4 的 deb sha256 + 装机逐字节 + m5 十二臂 39/0 PASS 交叉对账。日志中
  的仓库绝对路径前缀已统一脱敏为 `<repo>/`，其余逐字节为运行时 stdout。
