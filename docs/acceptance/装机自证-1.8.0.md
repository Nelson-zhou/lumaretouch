### 眼牙那一臂（第 8 臂，单独一个露齿夹具窗口）

```
M0_ENHANCE {"amounts":{"iris":0.5,"sclera":0.6,"teeth":0.7},"lit":true,
 "gatedPx":{"iris":454,"sclera":472,"teeth":706},
 "geomPx":{"iris":506,"sclera":582,"teeth":2356},
 "reason":{"iris":null,"sclera":null,"teeth":null},
 "window":[189,131,147,139],"device":"cuda","bytesEnhance":490392,
 "enhanceMs":54.9,"buildMs":13.6,"mouthOpenness":0.3292,"canvas":"400x504",
 "insideChanged":1769,"outsideChanged":0,"backHomeBytes":0}
```

判据逐条：三个数原样递到引擎（宿主没替谁填零）；`lit=true`；每一格要么有覆盖格、要么
有引擎报的原因（DoD §3「未接通显式禁用并说明原因」在真窗口里成立）；牙齿那一格在露齿
夹具上点亮（`gated_px=706`、嘴开度 0.3292——闭嘴样本上它该被拒而不是被点）；
`insideChanged=1769 > 0`（不是假滑块）；**`outsideChanged=0`**（窗口外逐字节不动，
"局部增强偷成全图提亮"这条错进不来）；**`backHomeBytes=0`**（关掉那层回到出厂帧逐字节，
`bytes_enhance` 归 0，常驻场真放掉了）。

`enhanceMs=54.9` 这一格读的是"到 `apply_enhance` 那个同步点为止这块卡上排着的活"，
真窗口里同进程还有帧通路在跑靶，所以它必然大于这一层自己的代价——**这一层的成本以
性能台账为准**（下一节）。这条归因写在判据注释里，不留一个能被误读的数。

读数汇总：**31 条通过，0 条不过 → `VERDICT=PASS`**（版本 1.8.0）。

## 5. 本轮定版过程中抓到并修掉的（都按缺陷处理，没有一处靠重跑变绿）

1. **星形栅格是外偏不是内偏**：极坐标半径线性插值给出 `r/cos(Δθ/2)`，解析正方形对拍时
   框外 420 格拿到满额度（Δθ=90° → +41.4%）。改成逐射线—边段精确求交，并更正模块注释里
   方向写反的那句结论。（ADR-0015 §2.2）
2. **窗口把软边硬切**：`REGION_PAD_PX=6` 兜不住唇环 feather（实测 ≈15 px）。改成
   "先算 feather 后定 pad"，并加一条能负向自证的用例。（§2.3）
3. **`wc` 把 hsv 往返的 1e-17 混进画面**：只开牙齿时 114347 格眼白与源片不等——8-bit
   看不见，16-bit 直通导出上是真实改动。改成只统计点火了的子层。（§2.4）
4. **会话重挂臂 `pc` 未定义**（任何换设备/切文档必炸 `NameError`）：接线时留下的，
   库层 41 条盖不到它。
5. **`_emit_enhance_state` 位置传 `info`** → 第一条 enhance 命令就 TypeError；改关键字传，
   并把这条教训写进注释（命令签名改动必须有一条端到端兜着）。
6. **事件缺平铺 `lit`/`gated_px`**（`KeyError: 'lit'`）：组装点补齐，与 `deform_done` 同形。
7. **`reason` 同名不同形**：事件那份是整层一句话，`doc_state` 那份是逐子功能映射；UI 在
   字符串上取下标恒 undefined → "禁用带原因"这句话在屏幕上读不到。TS 侧两形分开并在
   `enhanceStateOf()` 一处归一。（§2.6）
8. **`enhance_ms` 恒 0 的计时**：账取在 `_write_current_frame` 之前，第一条命令永远报
   "这层不要钱"，而真窗口判据把它读成假红。改成先出帧后组装那一帧的账，并新增性能臂
   拿隔离读数当这一层的成本证据。（§2.9）
9. **拖滑块每次重画掩膜**：非零 set 无条件 `build_enhance`（实测 12–22 ms/事件）。改成按
   关键点指纹复用场，`enhance_rebuilds_during_drag == 0` 钉进台账。（§2.9）
10. **`edits` 名单落了一格**（`test_protocol` 切文档那条报红是**对的**）：`_state_edits`
    加了 `enhance`，两处字面量名单同步——这就是"名单双向守卫"要的形状。
11. **打包门禁抓映射落后**：新加性能臂后 `case-map.json` 落后于源码，`build-deb.sh` 里的
    运行时测试段直接拒绝出包（`× case-map.json 落后于测试源码：['PORTRAIT-009']`）。
    重跑 `map --write` 之后才放行——这条门禁的存在理由就是这一记。
