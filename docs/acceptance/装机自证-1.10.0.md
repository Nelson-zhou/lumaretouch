## 3. 本轮抓出并修掉的缺陷

1. **空状态之外的首屏白屏隐患**：`getCurrentWindow().onDragDropEvent(...)` 在无宿主时
   **同步**抛（读 `__TAURI_INTERNALS__.metadata`），useEffect 里逃出的同步异常会把整棵
   React 树打崩。浏览器预览曾因此只剩空 body。拖拽已改为可选能力：`try/catch` 之后
   跳过监听，界面照常（DoD §3：不许有起不来的界面）。
2. **一次点击入口不是一次点击**：旧的「选择…」只填路径，还要再按「导入」。空状态卡片
   与顶栏按钮改为共用 `openAndImport()`：开框 → 选完立刻导入。
3. **过滤器名单两处**：抽成 `imagePatterns()`，与 `onPickPath` 共用引擎 ready 报的
   `image_exts` 一份（GTK 大小写敏感的双份模式理由留在原注释）。
