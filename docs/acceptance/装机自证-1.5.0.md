## 本轮新增那一臂在看什么（LNX-PORTRAIT-004 覆盖与继承）

第 6 臂与第 5 臂同一轮窗口、同一份日志（`LRT_AUTO_FACE=1` 一起点火），量的是形变的
**作用层**：`scope=all` 改全人物默认、`scope=person` 只给当前选定那一张挂覆盖、
`action=inherit` 恢复继承。库里那八段判据连的是裸引擎，而这一臂要穿过的层是
`runDeform(…, scope)` → Rust `deform` 的第三个参数 → 引擎 `deform_done` 的
`scope/overrides/overridden_kinds/inherited` → 宿主轮询状态 → 用户看见的那一帧。
六句话缺一不可：

1. `scope=person` 真的递到了引擎：`personScope=person`、
   被单独覆盖的名单 `['big_eye']`，而 `inherited` 当场为假；
2. 生效值是**合成**出来的（脚本原话）：`生效值 = 默认打底 + 覆盖盖上：
   {'big_eye': 0.9, 'slim_face': 0.2, 'small_chin': 0}`；
3. 冻结件 then 前两句——改默认（slim 0.2→0.6）时覆盖项继续生效、未覆盖项跟随：
   `{'big_eye': 0.9, 'slim_face': 0.6, 'small_chin': 0}`；
4. 冻结件 then 第三句——恢复继承后全部按层级合成：`{'big_eye': 0.3, 'slim_face': 0.6, 'small_chin': 0}`，
   名单里覆盖项 0 条；
5. 挂覆盖只动被选中那一张：`insideChanged=51233` 而
   `otherChanged=0`（1.6× 脸半对角之外一格不许动，半径出处
   见 ADR-0009 §2）；
6. **同一层级状态 → 同一幅画面**：走两条不同命令路径（先覆盖再 inherit，与先改默认
   再改回来）最后 `sameLayerBytes=0`。这一条是"合成只有
   一个出处"在对拍，非 0 就说明默认与覆盖各算了一遍。

第 5 臂（分人编辑）本轮仍逐条过：`numFaces=2`、未选定整条拒且画面
0 字节、`pickSource=face_selected`、`changedBySelect=0`、
`insideChanged=55018` 而 `outsideChanged=0`、
`support_share=0.3316`。

诚实边界：一层形变服务一张脸。同一时刻只有被选中那一张按"默认 + 它自己的覆盖"生效，
换人即换那份几何；这一版不做"多人同时各改各的"，也不做跨图认同一人（PORTRAIT-005）。
