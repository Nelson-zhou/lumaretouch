# 影楼人像工作流 · 逐项差距表（审查整改 267beb3 之后）

> 目的：落实总目标第三阶段"先更新逐项差距表"与第七阶段"交付剩余缺口"。
> 每一行给出 **需求出处 · 代码入口 · 实现状态 · 实际验证 · 剩余工作**，状态口径至少区分
> `已实现·CPU已验` / `部分实现` / `仅界面占位(明确禁用)` / `未实现` / `无法端到端验证(需GPU窗口)`。
> **不把"代码存在"当成"功能验收通过"**：像素级/上屏级效果一律标 `无法端到端验证(需GPU窗口)`，
> 因为端到端跑测会打满 ROCm（历史上因此死机），须在受控 GPU 窗口与授权下补跑。
>
> 采集基线：本地 `master`（本会话最新提交，含 ADR-0023 定档）。数据源：`tools/check-p0-coverage.py`
> 静态门禁（本轮实测：36 格全登记、29 格接进命令面、7 格显式禁用带原因、六个分栏都在用、反向门禁有效）、
> `docs/acceptance/cases-frozen.json` 冻结用例、本会话逐项核实与提交。
>
> **本轮重跑当前版本（非沿用历史 964/8/1）**：在 `CUDA_VISIBLE_DEVICES=""` 下补跑了 35 个非引擎子进程/
> 非模型套件的 CPU 测试文件（export*/decode*/geometry/tasks/scope/acceptance_tool/presets/grade/tone/hsl/
> lut/exposure/history/quant/project/enhance/light/deform/inpaint/guided 等），全绿；其中一批暴露并由
> 本会话先前提交引入的 3 处自我回归（误用汉字、码位 U+62C4、不在此复现、16-bit 错误消息锚点漂移、case-map 未重生），已修复
> （见提交 5291dd2 与对应回归）。模型/设备相关套件（session/vram/raw/matting/pick/upscale）本轮已随
> 下面的全量 CPU 扫（876 例）一并跑过——torch 在 cuda 不可用时落 CPU 回退路径；当时仅留引擎子进程
> `protocol`/`shm` 与基准 `perf_report` 未跑，见下条补齐。
> **本轮（`edd82ae`）再补**：引擎子进程套件 `test_protocol.py`+`test_shm.py` 也在 CPU（`CUDA_VISIBLE_DEVICES=""`，
> 无 GPU 负载/无 BACO 风险）上补跑通过（161 passed / 5 skipped / 0 failed）；连同产品形状分位（`test_perf_report.py` 6 例），
> **当前 HEAD 自动化全量 = 1043 passed / 15 skipped / 0 failed（CPU，权威一遍见 `docs/acceptance/验收报告.md`，1.12.1）**。仍需受控 GPU 窗口的不是“跑不跑通”，
> 而是**像素级/上屏视觉**人眼复核（肤质/身份/边缘/背景）与 clean CPU 轮子的裸机装机——这两类靠加时长补不了，需真实设备与授权。
> **工具链验收也在当前版本（`1b164d4`）重跑，不沿用历史“前端构建通过、Rust 检查（补 staging 后）通过”**：

> **CPU 端到端导出视觉自证（新增）**：`packaging/cpu-visual-accept.py` 拿真测试人像走实际导出通路
> `export_image(device=cpu)` 出 before/after（VERDICT=PASS，恒等位逐字节==原图）；人眼核对：磨皮肤色窗内平滑、
> 发际/眉/眼/唇边缘锐利、背景不动；调色肤色偏暖且守作用域；换底（P1-2）遮罩外整片换成背景色、主体保留——

> 诚实边界：合成矢量夹具验的是窗口化/保边/作用域结构正确性，非真实客片肤质观感（后者仍需 GPU 窗口 + 真照片）。

## 四、剩余缺口汇总（须外部条件才能推进）

1. **需 GPU 窗口 + 授权**：端到端像素/上屏视觉验收、预览↔导出像素一致、人物效果前后图（肤质/身份/边缘/背景）。
   （注：自动化全量回归已在 CPU 重跑当前版本通过——1043 passed/15 skipped/0 failed（`tools/run-acceptance.py` 权威一遍），见验收报告；结构级像素自证
   （`cpu-visual-accept.py`：磨皮窗口化/保边/背景不动、调色守作用域、恒等位逐字节）也已在 CPU 过。需 GPU 窗口的只剩
   真实客片肤质观感与上屏交互帧率，不是 pass/fail 跑测，也不是导出算法的结构正确性。）
2. **需产品拍板**：已由用户授权“按默认方案”而定档（ADR-0023：P1-3 意图/源策略、16-bit 首版双路模型）；
   float32 全链按手册列为后续里程碑（不在首版）——无待定项。
3. **需无 GPU 裸机环境**：P0②装机级验收。
4. **功能本身待建**：蒙版视口叠加通道、遮罩羽化、痣/疤痕身份标记保护、按需全分辨率精帧渲染。
5. **资料一致性**：独立 Word 原件多次下载失败（ZIP 内手册已全读、必要图片已核）；Word 全文排版仍未逐页核对。
   原件逐字节一致性已单独立册并实算核对：规格 JSON（功能矩阵）4 个文件重算 sha256 全等于 `spec/manifest.json` 登记指纹，
   缺失原件清单与状态见 `docs/acceptance/原件一致性与缺失资料清单.md`；安装/启动/各变体（含 `--variant cpu` 无 GPU 降级）/定档行为见 `docs/运行说明.md`。
