## 2. 裸环境真窗口七臂（`packaging/m5-release-check.sh`）

全程不带任何 `LRT_*` 开发变量，也不指回仓库。七臂抬头与最终读数（原样）：

```
── 1. 装机的包：账要对得上刚打的那一份
── 2. 运行时：候选表要真命中装好的那一份
── 3. 裸环境真窗口：剔除所有 LRT_* 后启动装机壳
── 4. RAW 那一臂：拖进 DNG 也要即刻解码、重塑、出片
── 5. 分人编辑那一臂：多人图里点选一个人，另一个人在用户看见的那一帧上逐字节不动
── 6. 层级那一臂：全人物默认 + 逐张覆盖 + 恢复继承（LNX-PORTRAIT-004）
── 7. 挑图那一臂：一组照片里量出近似组/糊/过曝/疑似闭眼，而原片一个字节都不动（LNX-PICK-001）
── 读数：29 条通过，0 条不过
VERDICT=PASS — 装机件在裸环境里自证通过（版本 1.7.0）
```

本轮值得记的几条原始读数（不是转述 ✓，是脚本打印的数）：

- 第 4 臂：`DNG 直通导出的是满幅真解码：引擎报 768×600，期望 768×600`；代理档 512×400；
  `导出没动 RAW 原片：导入前后哈希同为 19e3cc0c42a9…`。
- 第 5 臂：真检测器报出两个人 `numFaces=2`；未选定 → `blocked=True`；选定 1 号后

  被选那一张动了 `insideChanged=52517`，另一圈 `outsideChanged=0`。
- 第 6 臂（本轮改逐格判之后）：合成字典如实带着四格——
  `生效值 = 默认打底 + 覆盖盖上：{'big_eye': 0.9, 'slim_face': 0.2, 'small_chin': 0, 'smile': 0}`、
  `改默认 → {'big_eye': 0.9, 'slim_face': 0.6, 'small_chin': 0, 'smile': 0}`、

  `两条路径走到同一个层级状态而画面差 0 字节`。
- 第 7 臂：5 枚建议徽章真画进 DOM、`measure_ms=779.7`、跑完后输入 sha256 逐字节不变。

## 5. 本轮定版过程中抓到并修掉的三处（都按缺陷处理，没有一处靠重跑变绿）

1. **m5 层级那一臂写死三键字典**：`smile` 进 KINDS 后合成字典多一格，报红 28/1、
   `VERDICT=FAIL`。改成逐格判（显式设过的逐格等于设计值 + 没碰过的必须为 0），
   并配守卫用例；对归档的一手窗口日志重放：12 项读数全 ✓、exit 0。
2. **执行器认错帧**：`_cmd_frame` 原来"排空队列 + 取下一帧"，改成"取 freshest 的 seq 之后
   第一帧"仍错——探针抓到请求 `value=1.0` 而拿回的那一帧事件自己写着 `strength=0.0`。
   现按这一笔的回执（`params_set` 等）在事件流里的位置认帧，并要求帧自带的 `strength`
   与请求值对账。P0 中性那条由此从"偶发红"变成确定性通过。
3. **文案与注释里写死形变格数**：面板那句「三格全部跟随全人物默认」在四格的现在是一句
   当场的假话，改由 `len(KINDS)` 推；同批清掉 12 处旧计数。

详细成因与"为什么不选另一种"见 `docs/adr/0014-release-gate-false-reds.md`。
