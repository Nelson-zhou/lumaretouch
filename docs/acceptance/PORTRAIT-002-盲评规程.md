## 盲评方法

1. 每组样本产出两张 PNG：`strength=0`（未修饰）与 `strength=0.6`（基础肤质修饰），
   同尺寸、同色彩配置（sRGB 嵌入），文件名去掉配置信息（A/B 匿名）。
2. 评价者 ≥3 人，逐对判三个问题，二值作答：
   ① 皮肤是否仍看得见纹理（不是塑料/蜡）；
   ② 肤色是否发生可察觉漂移（与未修饰那一张比）；
   ③ 是否出现轮廓/发际/背景上的边界污染（晕边、白边、糊边）。
3. 通过判据：**三个问题各自的不通过票 ≤1/3**，且没有任何一位评价者同时判 ② 与 ③ 不过。
4. 记录设备与色域：显示器型号、是否校准、观看距离与环境光（写进下面的结果表）。
