# 人工签字簿 · 1.11.0（全项目只剩这两条要人签）

日期：2026-10-19　适用范围：`luma-retouch 1.11.0`
关联：`docs/acceptance/验收报告.md`、`PORTRAIT-002-盲评规程.md`、ADR-0017

## 为什么单独一本簿子

验收报告里还有两条 `manual_pending`：PORTRAIT-002（肤质盲评）与 PORTRAIT-007
（美型边界的外观审核）。这两条的**自动化那半已经全绿**，但判据原文要求人眼签字。
机器不能替人签——拿指标绿去冒充，就是这份报告最不该发生的事。

这本簿子把“还差什么、在哪里签”写死；签完之前，报告里它们仍然是 `manual_pending`，
不计入通过。
