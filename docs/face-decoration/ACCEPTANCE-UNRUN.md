# Face decoration acceptance matrix: UNRUN

These are required checks, not recorded passes. Source inspection, AST parsing,
hash verification and import-path existence cannot establish any row below.

## Numerical and rendering

1. All eight versioned patterns are distinct at useful portrait resolution;
   five are freckle designs and three are mole-style designs. Catalogue version
   and bytes reproduce after save, reopen, preset capture and full export.
2. Strength zero returns exactly zero contribution without native/model/support
   availability. Existing unrelated recipes and old saved projects stay neutral.
3. Immutable source buffers are unchanged. No mark changes pixels outside the
   intersection of measured support, review and conservative facial exclusions.
4. Invalid dimensions, non-finite values, unsafe source ranges, missing current
   source or unsupported landmarks fail before publishing partial results.
5. Small marks are stable when rendering proxy and master resolutions. Compare
   analytic pixel coverage against high-resolution area integration, including
   subpixel centres, rotated faces and tile/ROI boundaries. State the measured
   tolerance before acceptance; no numerical tolerance is asserted here.
6. Every export tile sees the same frozen face contribution. No seams, per-tile
   random pattern generation, alternate preview solver or RGB8 master path.
7. Small/strongly rotated/profile/edge-cropped faces refuse unsafe placement
   rather than silently substituting a face rectangle or mirroring a wrong side.
8. Eight original material assets are actually included with source and licence
   in the staged package, and unavailable/incorrect native ABI is visibly gated.

## Source ownership and persistence

1. Review belongs to the exact current effective source SHA, dimensions,
   FaceRef and landmark digest. Switching photo, analysis, selected face or
   original/derived base invalidates stale admission; original analyses are not
   reused for returned composites.
2. A real source image must be displayed before visible-skin paint and explicit
   ownership/occlusion acknowledgement. Paint uses the existing normalized
   source-pixel-centre convention and full decoded pixel-edge viewport, not
   preview-window or cropped output coordinates.
3. Review vectors are immutable project assets and re-rasterized at the actual
   render size. Undo/redo and portable project reopen retain the correct bytes;
   append-only history assets do not disappear when current support is replaced.
4. Review-only operations do not create a second history owner. Any unknown
   mutation result preserves the existing uncertainty fence and original
   correlated receipt, rather than retrying an active mutation blindly.
5. Scalars can be applied only to targets with independently valid target
   support. No donor landmark, mask, recovery vectors, cached crop or source
   image travels in a preset or batch intent.
6. Shared-source aliases and persistent cohorts obey the actual affected-set
   policy. A new operation must not bypass whole-set review/history guards.
7. Neutral reset remains possible when a model, native core or support asset is
   unavailable. An active invalid entry must not silently drop from a mixed
   recipe or become a partially applied preset.

## UI and photographs

1. Keyboard-accessible pattern selection, labelled strength, explicit neutral
   reset, native capability explanation and truthful missing-support feedback.
2. Paint add/subtract, clear, cancellation, repeated clicks, pending mutation,
   source switching, crop/repair changes and late callbacks preserve ownership.
3. Inspect actual before/after at full source pixel resolution, not an enlarged
   thumbnail. Reduced display evidence must be labelled separately from master
   precision; dark/deep skin, bright skin, compression and high-bit inputs need
   photographs rather than synthetic-only checks.
4. Glasses, hair, hands, jewellery, facial hair, lips, brows and neighbouring
   people must not receive accidental marks. Human review is still required;
   known exclusions are not complete automatic segmentation.
5. Original marks and natural texture must remain, except the deliberately
   added decoration contribution. No claim of removing original moles or
   reproducing the commercial product's exact artwork.
6. Complete ordinary workflow: import, select real person, inspect source,
   paint own visible support, choose material/strength, compare, undo/redo,
   save/reopen, supported target-local preset/batch, export. Measure peak memory,
   cancellation behaviour and latency with declared hardware and image sizes.

No tests, build, typecheck, product imports, inference, model download or photo
evaluation were performed in this source-only slice.
