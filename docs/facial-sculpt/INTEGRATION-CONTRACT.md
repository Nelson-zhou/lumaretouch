## Actual connected path

1. RetouchPanel dispatches the two existing handbook leaves to separate controls of FacialSculptPanel. Capability comes from the dedicated Rust ABI availability, not a fallback filter. Missing ABI disables activation without silently replacing the method. A neutral reset stays distinct from an absent inherited value.
2. The people workflow issues exact source-reference and mutating support-review requests. Engine and native validators bind document epoch/revision, graph and association revision, target, FaceRef, landmark digest, immutable effective source and source PNG hash. Only a proven read-only reference can pass pending-write fences or release image payload. Unknown mutations retain existing query-only recovery; closing the editor does not claim a submitted write was canceled.
3. The canonical support bank stores independent vector review, not a proxy-space bitmap. The ordinary people graph owns its pointer, history, project/package and undo. Support review stages a candidate graph and uses the existing canonical publication path. Scalar changes use the normal people patch route; no second undo owner is introduced.
4. Registry, photograph-wide validation and project restoration validate the new recipe. Every graph transition and candidate-render entry rejects cross-source changes and unseen shared-source aliases. This bounded entry does not register the optional transfer helper as a public batch/preset/cohort route.
5. Original and supported opaque SDR derived sources carry their own retained analysis and canonical support bank into prepare. The active source window is measured once with independently observed face skin, manually reviewed visibility, anatomy exclusions and all retained foreign-face boxes. Strictly neutral intent can keep dormant support; malformed or conflicted intent is not silently skipped.
6. CPU and canonical device pipeline both compose the immutable log-gain stage before geometry, including complete-source export. Export tiles crop the frozen field at the exact source origin, never refit a proxy or tile. Only common linear-light RGB gain is used with gamut headroom; no per-channel clipping or invented HDR/alpha support. The source image stays unchanged.
7. Shared memory admission subtracts already-owned analyses, geometry fields, preceding effects and recovery arrays before allocating review raster/native work. Native window limits and complete-neighborhood refusal remain explicit. These are source policies, not measured peak-memory or performance results.
8. Historical source-context version-1 proofs exclude only the newly introduced implicit neutral default. Every explicit new leaf, conflict, inherited override and local support pointer remains represented. Old recipes and old numeric kernels are not migrated or rewritten.

## Explicit remaining work

- No compiler, build, typecheck, product import, tests, numerical comparison, actual-image review, GPU/device parity or latency acceptance has run. A source-connected status is not functional acceptance.
- Current-photo visibility review can be painted and the result inspected in the canonical image canvas; there is no separate precommit full-image comparison ACK for scalar adjustment in this slice.
- Cross-photo presets/batch, persistent multi-photo person/group propagation, shared-source alias review and dedicated effect-recovery painting are not exposed here. They need their own target-local image review rather than donor support copying. They are deferred rather than removed requirements.
- Severe pose, small/cropped faces, poor skin evidence, insufficient review or oversized native windows refuse. Flat or unsupported neighborhoods can produce no measurable change. Existing image precision/codec limits remain; alpha/HDR are not flattened or clipped.
- A spatial broad-luminance estimator cannot separate real lighting from every marking, makeup or shading ambiguity. It cannot reconstruct 3D, recover clipped highlights or certify anatomical correctness.
