# Source-stage acceptance matrix: UNRUN

Every item is pending future authorized execution against the real native
libraries and genuine source images. No mocked image/native success may satisfy
these checks. The supplied JSON arithmetic fixtures are also unexecuted.

1. Validate exact UI context/review schemas and actual browser PNG verification:
   SHA, CRC, real decode, original dimensions, full-frame aspect, both sides
   presented and re-presented after remount. Inspect alpha-bearing and HDR
   photographs. PNG display clipping must never alter output asset bytes.
2. Capture a fully edited source through the existing complete export/capture
   path: include crop, geometry, layers, repairs and current derived content.
   Confirm the source hash is its canonical asset hash, not original-file hash.
   Wrong source, dimensions, colour/alpha contract, canonical identity, current
   revision or reopened epoch must reject before rendering.
3. Change input dictionaries immediately after capture, during preview snapshot
   and after a candidate is returned. Saved owner, recipe, depth and output bytes
   must remain identical; mismatched snapshot boundaries must reject. Returned
   dict edits must not modify retained captures or candidate validation.
4. Reject implicit/manual plane labels at the raster importer, missing/false
   acknowledgement, wrong session/source/request, nonconstant plane bytes and
   altered provenance. Verify 0.5 maps to little-endian u16 32768, including the
   UI's constant-plane verification. No automatic plane appears without action.
5. Import actual user-selected u16 depth at multiple whole-frame resolutions.
   Test canonical Base64/padding, SHA, endian, lengths, extreme aspects and exact
   centre mapping at source/raster borders. The upsampled processing hash must
   be computed from the bytes actually sent to the real bridge.
6. Any model label, guessed subject/segmentation or subject focus must refuse
   while provenance gates remain closed. Model installation alone cannot change
   this behavior. No imports, downloads, cache lookup or inference as fallback.
7. Rasterize hard/soft taps, repeated/long segments, source corners, nonsquare
   images, maximum/minimum/subnormal radius/feather, zero/full amount and flow,
   ordered clear/blur, duplicate IDs and limit boundaries. Verify preserved
   vectors, no hidden decimation, no NaNs, exact full clear -1 and work admission
   including whole-plane compositing. Inspect real rendered photographic masks.
8. Exercise every actual aperture, neutral zero/small radius, zero/full clear,
   depth intervals, negative/HDR/transparent source, occluding foreground edges,
   source borders and very large radius. Compare real native results and stored
   full output, not only reduced display images. No Gaussian/mock fallback.
9. Reject native missing/disabled/ABI mismatch/unsupported kernel, UI-positive
   falloff below 0.000001, invalid native results and native errors. No identity
   success, partial output, store entry, document change or history append.
10. Exhaust each explicit memory/tap/brush/request/deadline budget independently.
    Verify before allocation where specified, available-memory failure, second
    concurrent lens job refusal, slot release after each failure/cancellation,
    and bounded retained leases in the parent. Never reduce source/radius to fit.
11. Cancel during full capture, depth resampling, brush rasterization, native
    tile operation, canonical output verification and PNG encoding. Replace
    source/session while work is pending. No candidate crosses the cancelled
    fence and no job-local AssetStore record reaches the long-lived document
    store. Inspect released memory and stale result rejection.
12. Apply using exact and changed token/owner/session/recipe/before/after hashes,
    missing review flag, repeated request, unknown request outcome and late
    cancel. Stage only correlates; existing host request/receipt/history owner
    must perform atomic commit once. Neutral results append no history. Test
    undo/redo, save/reopen and full export only after shared wiring is complete.
