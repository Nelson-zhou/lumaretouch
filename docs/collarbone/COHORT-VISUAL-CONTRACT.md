# Persistent-cohort collarbone visual review

Baseline `b226f0b68d927ac62d20e50087d508f40fba0aad`.
Status: source-authored **UNRUN**, not functional or photographic acceptance.
Requirement `LNX-REF-PC-32465-C-abf0a5c8c9` remains **PARTIAL** because official
AI 3D detection and automation are absent. This is closure of an existing
operation's workflow gap, not an additional algorithm or feature count.

## Complete atomic cohort

Persistent association operations use the existing independently owned cohort
and existing atomic scoped ledger, not ordinary target-only transfer. The
source document is itself a member whose inherited values can change, so it
must be rendered and explicitly acknowledged alongside every target. Existing
constraints remain: 2..16 members including source, one selected verified face
per member, one retained document per independent owner, all saved members
present, and no source masks, curves, categories, pixels or identity borrowing.

Required visual review is computed from actual resolved data, not only the
request's module list. It applies when collarbone is newly selected, is in the
retained shared intent (including zero), or is active on any member's selected
face before or after staging. Therefore unrelated shared-parameter patches and
complete unlink cannot omit review merely by sending an empty or different
`module_scope`. The original selected module list is not silently rewritten.
The actual frozen plan records `collarbone_visual_required`; the public
`collarbone_cohort` marker reports that requirement, not caller authority.

`collarbone_cohort_review` resolves each member's candidate coverage from that
member's own FaceRef, source, graph and independent support. Before and after
use the same complete canonical renderer as the ordinary visual path. All
members are rendered before the association becomes a frozen review; later
member preparation cannot bless changed earlier evidence. Source is first in
the frozen ordered image/ack set. Missing or blocked members cannot be skipped.

Unlink keeps the existing explicit face overrides and removes shared person
intent. It can therefore remove an inherited collarbone effect. It does not
promise unchanged inherited appearance: the actual before/after pair must show
that transition. No legacy recipe is numerically reinterpreted.

## Image acquisition, approval and commit

The existing session-only raw PNG cache and exact paged side reads are reused.
The cache accepts a persistent plan only when its own frozen flag requires it,
its first target is the plan's source and no atomic member is blocked. Empty
selected modules on unlink do not remove that authority requirement. Private
random filenames, byte/hash checks, size budgets, pending-token expiry and
consumption cleanup remain unchanged.

The UI presents source-member and target-member coverage and actual image
pairs. Each loads via the frozen token/document/revision/side/hash request and
requires its own explicit acknowledgment. A source face-selection thumbnail,
association metadata or another member's checkbox cannot satisfy this review.
The whole ordered set, source first, is submitted in the one atomic command.

Before claim, the coordinator rebuilds the actual complete cohort and verifies
frozen source proofs, graph candidates, independent coverage, image identities,
all retained PNG bytes and the exact affected document-ID set. Preparation may
not expand or replace the cohort. Native/engine/UI validators distinguish this
cohort marker from ordinary selected-module detection; unknown and cached
receipts retain the exact token and ordered acknowledgment set. Read-only
acquisition remains separate from mutation recovery authority.

The existing scoped ledger retains commit/rollback and grouped undo/redo.
Project and history retain graph/source/support ownership, not review PNGs.
Temporary visual evidence need not survive accepted history replay. All those
runtime paths and interruption behavior still require real execution testing.

## Residuals and acceptance

- AI 3D clavicle points, automatic category/anatomy, physical relighting and
  photographic naturalness remain unimplemented or unaccepted as before.
- Every before/candidate chain must actually render. Stale support or invalid
  source dependencies refuse rather than manufacture an old image, silently
  skip a member or remove an existing effect just to make preflight pass.
  In particular, unlink of an old active collarbone whose old support/source
  cannot render may now refuse even when its candidate would be neutral.
  This is an explicit recovery limitation, not universal unlink availability;
  a separate truthful recovery path remains to be designed. Saved projections
  and history are not discarded to work around it.
- The 1024-edge RGB8 review images are reductions of real complete float
  rendering, not full-resolution precision inspection. 16 members and the
  128 MiB raw session cache are source bounds, not measured performance claims.
- Broad alpha/HDR remains unsupported. No clipping or flattening is introduced
  as a substitute for correct support.
- Current-photo preset visual review is still a distinct unfinished route.
  `PRESET-VISUAL-NEXT.md` documents why it needs a non-mutating shared portrait
  replay planner before mixed preset images can truthfully match application.
- Tests, product imports, native execution, filesystem cleanup, builds,
  typechecks, numerical/photo/quality/history/export acceptance are UNRUN.

No new external code, model or weights are used. Existing original
GPL-3.0-or-later renderer/storage/proof mechanisms are reused; the numeric core,
common geometry sampler and prior recipes are unchanged.
