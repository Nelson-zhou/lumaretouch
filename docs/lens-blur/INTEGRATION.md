## Actual path

plane consent → five original aperture kernels and source-owned clear/blur
strokes → full-resolution Rust candidate → actual full-image comparison and

`useLensBlur` owns request lifetimes independently of panel visibility.
`nativePort` invokes the dedicated protocol-2 native mailbox. Native admission
is one-use; generic and interactive dispatch cannot replay an admitted command.
`lens_blur_host` owns immutable source and candidate leases, and delegates the
actual new-copy transaction to the existing creative document host. Current,
manual-plane, preview and receipt commands are read-only; submit is not.
`read_job_ingress` is a real extraction of the prior reader controls, preserving
their order while adding lens cancellation. Full masks are source-owned, not
copied from another photograph. Display PNGs are RGB8 representations only;
canonical rendering consumes float source pixels, never a displayed thumbnail.

## Limits that remain requirements, not optional polish

- Automatic scene depth, subject focus, compatible model/runtime installation,
  model quality and default automatic experience remain unavailable. The guarded
  optional adapter does not activate merely because weight metadata exists.
- Ordinary 24MP full edited-source workflow is NOT supported by this slice.
  Existing full capture and full-grid stage memory reservations already exceed
  the bounded host budget; direct aperture work also grows quadratically with
  radius. Early admission rejects known impossible sources before painting.
  No global cap is raised and no final result is downsampled. A separate real
  capture/storage and renderer redesign is required, not merely smaller tiles.
- Actual per-source radius, refinement-work, memory and cooperative deadline
  bounds can refuse a candidate. Cancellation is a request, not proof of an
  immediately stopped bulk allocation, hash or solver.
- Photo return accepts opaque SDR only. Alpha/HDR incompatibility is refused,
  never silently clipped; this does not describe the broader Rust core gamut.
- Process-local receipts do not guarantee recovery after process loss. Unknown
  writes remain fenced and query-only. A positively reconciled copy can still
  leave global autosave conservatively tainted until an explicit safe project
  boundary; no unrelated taint is reset and no second copy is submitted.
- Batch/preset/cohort, editable reopened lens recipe, update-original, physical
  lens parity, true layered occlusion and globally conserved optical flux are
  not implemented/accepted by this path.
