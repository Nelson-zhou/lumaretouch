## 测试流程问题与修正依据

1. 空 `browserName` 是显式匹配要求，不等于省略；移除该字段后 session 成功。官方 tauri-driver 2.1.0 Linux 仅转换 `tauri:options`，不重写 browserName。
2. WebDriver execute 需要执行函数体并 return；未调用的箭头表达式导致空结果，不是应用白屏证据。
3. 单独设置 `LRT_LOAD_IMAGE` 不会在普通启动路径自动导图；本轮改为明确夹具装载，未把它当用户导入交互验收。
4. SVG 存在不等于可点击：侧栏是独立滚动裁剪区。点击前滚动、重取矩形并验证 `elementFromPoint`，不使用陈旧坐标。
5. 当前编辑状态来自 `doc_report.doc_state`；`image.doc_state` 是导入事件快照。帧计数不能独自证明某条编辑提交成功，需关联当前配方和回执。
6. 未满足加点前置条件时，不判撤销失败；测试脚本自身异常与产品错误分别记录。

官方依据：[tauri-driver 2.1.0 capabilities 转换实现](https://github.com/tauri-apps/tauri/blob/tauri-driver-v2.1.0/crates/tauri-driver/src/server.rs)、[Tauri WebDriver 指南](https://v2.tauri.app/develop/tests/webdriver/)。
