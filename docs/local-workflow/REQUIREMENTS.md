# Local workflow: bounded source slice

Exact original requirement: `workflow:8YEKwsjJg7`, source `工作流规格.json`,
index 26 in `docs/development/handbook-traceability.json`. The preserved source
specification is `ui/src/spec/workflows.json`, entry `8YEKwsjJg7`.
Official reference: https://www.pixcakeai.com/guide/8YEKwsjJg7 .

The v1 isolated Rust core provides a bounded linear graph, stable source-file
polling, durable per-occurrence operation identities, error policies and an
editable local definition UI. A graph is not runnable merely because it parses:
native/engine preflight must prove every actual port, source/project ownership,
output profile and destination. No mock execution or fabricated receipt exists.

The currently integrated minimal path is intended to be directory source →
managed import → optional local path labels → genuine fixed-profile export.
Compatible preset nodes remain unavailable unless their exact owner/review path
is supported by preflight. Stop fences further dispatch; it is not rollback and
never turns uncertain import/export into successful cancellation.

A dedicated lease means exclusive use of the exact current clean saved project,
not silently opening or saving a different project. Explicit release is required
for unused leases; unsettled effects cannot be released as completed work.

## Remaining handbook scope

ERP integrations, downloads, AI culling, colour matching, general branch/bucket/
loop graphs, cross-machine workflow import/export, arbitrary export profiles and
reviewed automatic preset application are not delivered by this minimal slice.
Local definitions are not a claim of all official template functionality.
Full process-restart recovery of engine-owned unresolved work remains missing;
durable intent alone does not recover an engine lease or prove an output.

All numerical, filesystem runtime, UI, hardware, build, test and end-to-end
acceptance is UNRUN. No algorithm count is added for transport or scheduling.
