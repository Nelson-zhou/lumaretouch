## Source-owned adjustment

The independent recipe is `{version:1, amount:0..1}`. Zero preserves the source;
positive amount requests an original local shrink of up to eight percent inside
the reviewed complete-head/hair plateau. This range and pivot policy are not
vendor-disclosed calibration. A requested unsafe amount refuses, never silently
attenuates. Both boxes and the pivot are explicitly marked on the actual source,
not inferred from a face oval, pose hips or a guessed hairline.

Own BodyRef, actual pose observation hash, current confirmed own FaceRef and
face evidence bind each review. The entire measured face and head observations
must lie inside the manually reviewed complete-hair plateau. The larger clear
transition ends above both actual shoulders. Other retained bodies/faces,
including disabled records, still protect their pixels. No transferred source
support or cross-person implicit association is allowed.

## Canonical integration

The Rust kernel returns a continuous inverse displacement, not a resized bitmap.
A new active order follows body chain v8 while neutral new intent preserves old
order identities. Original and immutable derived sources use the existing body
bank, body/face composition, one image sampler, history and export routes.
No second undo owner, render buffer asset or original-source analysis substitute
is introduced. The original file remains untouched.

Native and UI use the existing source-bound command/publication pattern. The
source workspace supports explicit boxes and pivot, ownership confirmation and
zero/reset/disable. An unavailable native core may retain independent review
with rendered=false, but cannot claim a nonzero adjustment applied. Neutral reset
or disable can still publish an actually rendered canonical neutral result without
loading an inactive kernel. Uncertain
mutations are queried by their original identity rather than blindly resent.

## Limits and remaining work

- No automatic whole-head/hair segmentation or 3D reconstruction.
- Hair touching shoulders, occlusion, crop, unclear transition and foreign-owner
  overlap may refuse rather than exclude hair from a supposed complete-head edit.
- Background/neck transition may deform; a manually reviewed rectangle is not a
  semantic matte or proof that all hair was actually marked correctly.
- Scalar preset/batch target-local review is not wired in this initial slice;
  private recipe copying is not an end-user transfer implementation.
- Existing derived opacity/SDR and broader alpha/HDR restrictions remain.
- All fixtures, builds, numerical behavior, native/UI interactions, performance,
  exports and photographic acceptance are UNRUN here.
