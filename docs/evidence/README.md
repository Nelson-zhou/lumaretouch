# 验收证据（生成物，可复现）

这里只放**里程碑验收要求留下的图**，每张都写明是怎么生成的；跑靶的默认输出目录
`build/` 不入库（它是每次重跑都会变的生成物）。

## m2-a-cheek-compare.png — 质感磨皮的毛孔保留对照

生成命令（仓库根，GPU 侧解释器按本机实际情况替换）：

```
PYTHONPATH=engine/src REPS=5 LRT_FRAMES=40 \
  python packaging/m2-skin-bench.py            # 默认写到 build/m2-skin/
```

取真图代理档 672×848 的脸颊 120×120 区域做 3× NEAREST 放大四联。
**日期 2026-10-16，RX 7600 XT / ROCm。**

| 格 | 内容 | 脸颊细带（毛孔） | 脸颊中带（色斑/光影） |
|---|---|---|---|
| 1 | 原图 | ×1.000 | ×1.000 |
| 2 | 盒式模糊 r=8（没有频域分离的"磨皮"） | ×0.107 | ×0.609 |
| 3 | **M2-a 默认（broad0/mid0/tex1）** | **×1.000** | ×0.738 |
| 4 | M2-a tex=0（把肌理关掉，塑料脸对照） | ×0.136 | ×0.585 |

看点：第 3 格的颗粒（毛孔）与第 1 格同样清楚，而那颗痣被压淡、唇线仍然锐利；
第 2、4 格一片糊。可验证的保留率不是靠看图，而是 `m2-skin-bench.py` 第一部分在
**成分已知**皮肤靶上的最小二乘回归：孔 0.987 / 斑 0.402 / 边 0.929（选择性 2.46），
而任何半径的传统模糊都是 孔 ≤0.013 / 斑 ≥0.83（选择性 ≈0.01）。

## cpu-visual-skin.png / cpu-visual-grade.png — CPU 端到端导出视觉自证（左原图 / 右结果）

生成命令（仓库根；`CUDA_VISIBLE_DEVICES=""` 走 CPU，无 GPU 负载）：

```
CUDA_VISIBLE_DEVICES="" PYTHONPATH=engine/src \
  python packaging/cpu-visual-accept.py        # 默认写到 build/cpu-visual/，此处为缩略入库件
```

拿真测试人像走**引擎实际导出路径** `export_image(..., device="cpu")`（与 GPU 同一条产品通路，
vram cuda→cpu 回退）出 before/after。看点：
- **skin**（磨皮 s=1.0）：肤色窗内（脸/颈）颗粒被平滑，而发际/眉/眼/唇**边缘仍锐利**、
  **背景颗粒不动**——证明磨皮是肤色窗内的、不越界带跑结构与背景；恒等位导出逐字节==原图（脚本内断言）。
- **grade**（肤色定向）：肤色偏暖偏亮，结构与背景基本不动——证明调色确有像素作用且守作用域。
- **bg**（换底入导出，P1-2）：给一张前景椭圆遮罩 + 醒目品红背景色，导出后**遮罩外整片变品红、遮罩内（主体）保留原图**
  ——直接否定旧 bug“换底只活在预览、盘上没换”；背景角实测 = 设定色 [230,26,230]。（合成椭圆遮罩+测试色，验的是
  合成真的进了导出文件，非真实抠图质量。）
- **deform**（脸部形变入导出，核心工作流）：`slim_face=1.0` 强形变，导出后**下颌/脸侧可见收窄、眼/鼻/唇随脸连续位移**
  （无撕裂/无 NaN），而**灰色背景与肩胸逐字节不动**（顶角实测 byte-equal）——直接回应“检查边缘和背景变形”。
  （解析正面关键点作在合成矢量脸上，验的是几何 warp 连续/局部/背景不受，非真实人脸重塑观感。）

诚实边界：夹具是 `make-test-portrait.py` 合成的矢量脸 + 颗粒噪声，验的是**窗口化/保边/作用域**这类
结构正确性，**不是真实客片的肤质观感**；真实照片的观感复核与交互帧率仍属受控 GPU 窗口那一轮。
入库为 0.45× 缩略（合成颗粒 PNG 很大），全分辨率可用上面命令随时重跑。
